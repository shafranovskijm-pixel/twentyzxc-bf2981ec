

## План: Атмосферные декоративные элементы из баннеров по всей странице

Суть: сейчас тема задаёт только баннер сверху и цвет фона, но остальная страница «пустая» — нет ощущения погружения. Нужно добавить декоративные элементы из баннерной картинки, которые «проступают» в разных местах страницы: углы, подвал, боковые области.

### Что делаю

Для каждой активной темы добавляю **декоративный слой** — абсолютно позиционированные копии баннерного изображения с сильным blur, низкой opacity и маской, размещённые:

1. **Нижние углы основного контента** — баннерная картинка проступает снизу слева и справа (opacity 0.06-0.1, blur 20-40px, clip-path или mask-image для плавного затухания)
2. **Зона футера** — над футером полупрозрачная полоса с баннером, создающая ощущение «возвращения» темы
3. **Правый верхний угол** (за основным контентом) — лёгкий блик из баннера

Каждая тема получит свои настройки расположения через новое поле в `AdminTheme`:

| Тема | Декор |
|------|-------|
| **Свежесть** | Фрукты/зелень проступают в нижних углах |
| **Офис** | Растение и элементы офиса проступают снизу-справа и в футере |
| **Нью-Йорк** | Силуэт города пробивается в углах (как на скриншоте — уже хорошо) |
| **Закат** | Тёплое свечение пальм в нижней части |
| **Минимализм** | Озеро/горы проступают в подвале и по краям |

### Технически

**`src/pages/Admin.tsx`:**
- После `<ThemeAnimation>` и перед `<AdminSidebar>` (внутри корневого `div`) добавлю компонент `<ThemeAtmosphere theme={activeTheme} bannerUrl={bannerUrl} />`
- Этот компонент рендерит 3-4 `<img>` элемента с баннером, каждый с:
  - `position: fixed` / `pointer-events: none` / `z-index: 0`
  - Разные `object-position` для показа разных частей картинки
  - CSS `mask-image: radial-gradient(...)` для плавного растворения
  - `filter: blur(...)` + `opacity: 0.05-0.12`
- Все элементы декора `pointer-events-none` и под контентом (`z-0`)

**`src/data/admin-themes.ts`:**
- Без изменений в интерфейсе — достаточно существующих `bannerUrl` и `id` для определения позиций
