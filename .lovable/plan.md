
# Улучшения дизайна страницы «О нас»

## 1. Интерактивный Hero-раздел с анимацией появления

**Текущее состояние:** Статичный заголовок с базовыми декоративными элементами.

**Улучшение:** 
- Добавить поэтапную анимацию появления (как на главной): сначала вертикальная линия растёт сверху, затем появляется иконка бриллианта, потом текст
- Добавить эффект parallax для фоновых элементов при скролле
- Крупный логотип "ZXC" на фоне с анимацией shimmer

---

## 2. Секция "Наша история" с Timeline

**Новый раздел:**
- Вертикальная линия времени с ключевыми вехами компании
- Каждая веха — карточка с годом, событием и описанием
- Анимация появления при скролле (элементы появляются поочерёдно)
- Золотые точки-маркеры на линии

---

## 3. Интерактивная секция "Принципы" с 3D-эффектами

**Текущее состояние:** Статичные карточки с иконками.

**Улучшение:**
- Добавить эффект наклона карточек при наведении (tilt effect)
- Анимированные иконки с пульсирующим свечением
- При наведении — карточка "всплывает" с тенью и свечением
- Добавить соединительные линии между карточками

---

## 4. Секция команды / основателя

**Новый раздел:**
- Фото основателя или абстрактный портрет в стиле luxury
- Цитата или личное сообщение с анимацией печатающегося текста
- Подпись с росчерком (SVG-анимация)

## 5. Интерактивная карта "Процесс работы"

**Улучшение секции экспертизы:**
- Заменить статичные карточки на интерактивную диаграмму
- 5 этапов: Анализ → Концепция → Дизайн → Разработка → Запуск
- При наведении на этап — разворачивается детальное описание
- Соединительные стрелки с анимацией

## 6. Галерея достижений / наград

## Технические детали реализации

### Новые компоненты:
- `TimelineSection` — вертикальная линия времени
- `TiltCard` — карточка с 3D-эффектом наклона
- `ProcessFlow` — интерактивная диаграмма процесса

### Анимации:
- Использование `useInView` для появления при скролле
- CSS-анимации для tilt-эффектов
- Framer Motion или CSS transforms для parallax

### Стилизация:
- Сохранение luxury-стиля (золотые акценты, тёмный фон)
- Добавление gradient-gold-text для ключевых элементов
- Shimmer-эффекты на интерактивных элементах

---

## Рекомендуемый порядок внедрения

1. **Анимация Hero** — наибольший визуальный эффект
2. **3D-карточки принципов** — повышает интерактивность
3. **Timeline истории** — добавляет глубину бренду
4. **Процесс работы** — практическая польза для клиентов
5. **Сворачиваемые реквизиты** — улучшает UX
