# Единая история всех документов

## Что не так сейчас

Вкладка «История» показывает только записи из таблицы `generated_documents` (договоры, счета, акты). За её пределами остаются:

- **Акты сверки** — генерируются, но в фильтре истории нет цветной плашки (тип `reconciliation` не классифицирован).
- **Файлы договоров** (`contract_files`) — все PDF в хранилище: подписанные сканы, ручные загрузки, повторно сгенерированные документы.
- **Документы НМО** (`nmo_documents`) — заявления, обязательства, сканы лицензий.
- **Подписанные PDF** из карточки «Подписать PDF» — сейчас вообще нигде не сохраняются, только скачиваются.

Из-за этого «История» неполная — часть документов есть, часть теряется.

## Что сделаю

### 1. История как единый хаб документов
Соберу в одной таблице данные из всех источников и помечу источник цветной плашкой:

| Тип | Цвет | Источник |
|---|---|---|
| Договор | синий | generated_documents |
| Счёт | зелёный | generated_documents |
| Акт | янтарный | generated_documents |
| Акт сверки | фиолетовый | generated_documents |
| Подписанный PDF | золотой | contract_files (по метке) |
| Файл договора | серый | contract_files (прочее) |
| НМО | бирюзовый | nmo_documents |

### 2. Фильтры и поиск
Сверху таблицы добавлю:
- Поиск по названию/номеру/клиенту (одна строка).
- Фильтр по типу — мульти-кнопки (toggle): Все / Договор / Счёт / Акт / Акт сверки / Подписанный / Файл договора / НМО.
- Фильтр по периоду — пресеты «7 дней / 30 / 90 / Всё» + выбор диапазона.
- Сортировка по дате (по умолчанию — новые сверху).

### 3. Действия в строке
Для каждого документа: «Просмотр» (HTML — в iframe, PDF — в новом окне), «Скачать», «Удалить».

### 4. Подписанные PDF попадают в архив
В карточке «Подписать PDF» добавлю выбор клиента/договора (необязательно). Если выбран — после нажатия «Скачать PDF» подписанный файл автоматически уходит в `contract_files` с пометкой `signed=true` и сразу появляется в Истории.

### 5. Счётчики
В шапке Истории — небольшие плашки со счётчиками по каждому типу за выбранный период (напр. «Договоры: 12, Счета: 12, Акты сверки: 3»).
