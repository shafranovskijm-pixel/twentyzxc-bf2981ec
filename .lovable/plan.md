# Превью письма + отчёт для ChatGPT

## 1. Превью текста письма прямо в окне «Рассылка»

Сверху панели — компактный блок «Шаблон письма»:

```
📨 Шаблон письма                                  [Изменить] [Свернуть]
─────────────────────────────────────────────────
Тема: Дистанционное обучение для {org} — 15 минут демо
─────────────────────────────────────────────────
Добрый день.
Меня зовут Максим Шафрановский. Я развиваю платформу…
(первые 6 строк, далее «…ещё 12 строк»)
```

- Берётся текущий subject/body (тот же, что для одиночной отправки).
- Кнопка **«Изменить»** открывает существующий диалог «Шаблон письма».
- Кнопка **«Свернуть»** прячет блок, если мешает.
- Под полем — подсказка: `{org}` и `{contact}` автоматически подставятся для каждого лида.
- Кнопка **«Предпросмотр для первого лида»** — показывает уже подставленный текст так, как уйдёт первому получателю.

## 2. Отчёт для ChatGPT

Во вкладку «История» добавлю кнопку **«Скопировать отчёт для ChatGPT»** (и рядом «Скачать .txt»). Отчёт — компактный текст за выбранный период (сегодня / 7 дней / 30 дней), который удобно вставить в чат:

```
Отчёт по рассылке СИНТАГМА за 12.06.2026

Всего писем: 20
✅ Отправлено: 18
⏳ В очереди: 0
❌ Ошибок: 2

Получатели (отправлено):
- info@comnews.ru — Comnews, группа компаний — 10:00
- alfaseminar@bk.ru — Альфа, ООО — 10:10
…

Ошибки:
- shadrin@somatip.ru — SMTP timeout
- orator95@mail.ru — Mailbox full

Конверсия: ответили — 0, демо назначено — 0 (заполняется вручную)
```

Также добавлю **«Скачать CSV»** — для Excel/Google Sheets (дата, email, организация, статус, ошибка).
