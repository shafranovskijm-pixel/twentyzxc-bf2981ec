

## Plan: Пагинация для таблиц (10 по умолчанию, выбор 15/30/50)

### Что делаем

Добавляем пагинацию в 4 таблицы: Договоры, Клиенты, Файлы и Документы. По умолчанию показываем 10 записей, внизу таблицы — переключатель количества (10, 15, 30, 50) и кнопки "Назад/Вперёд".

### Файлы

- **`src/components/admin/ContractsTab.tsx`** — после `filtered` добавить `pageSize` state (default 10), `currentPage` state, слайсить `filtered.slice(start, end)`. Внизу таблицы — Select с вариантами 10/15/30/50 + навигация по страницам
- **`src/components/admin/ClientsTab.tsx`** — аналогичная пагинация для списка клиентов
- **`src/components/admin/FilesTab.tsx`** — пагинация для папок (контрактов)
- **`src/components/admin/DocumentsTab.tsx`** — пагинация для списка документов (вкладка "История")

### Компонент пагинации

Общий блок внизу каждой таблицы:
```text
Показано 1-10 из 85  |  [10 ▾] [15] [30] [50]  |  [← Назад] [Вперёд →]
```

- `pageSize` сохраняется в `useState` (сбрасывается при фильтрации/поиске на page 1)
- При смене `pageSize` — сброс на page 1
