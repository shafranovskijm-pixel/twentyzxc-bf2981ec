

# Улучшение визуала шаблонов до уровня настоящих сайтов

## Главная проблема

Сейчас все блоки рендерятся **строго вертикально** в одну колонку с одинаковым отступом `space-y-4`. Это делает даже стильные шаблоны похожими на вертикальный список, а не на реальный сайт. Настоящие сайты используют горизонтальные лейауты, группировку элементов и визуальное разнообразие.

## Решение

### 1. Горизонтальная группировка счётчиков и icon-text блоков

Когда несколько блоков `counter` или `icon-text` идут подряд, оборачивать их в горизонтальный flex/grid контейнер вместо вертикального стека.

**Canvas.tsx и PlaygroundView.tsx**: Добавить логику группировки — при рендере определять последовательности однотипных блоков (`counter`, `icon-text`) и выводить их в `grid` с 2-4 колонками.

### 2. Полноширинные hero-изображения

Для изображений с `borderRadius: '0px'` и `padding: '0px'` — убирать внешние отступы, чтобы картинка занимала всю ширину канваса. Это создаст эффект hero-баннера.

**Canvas.tsx**: Условие для image-блоков — если padding и borderRadius нулевые, рендерить с отрицательными margin для компенсации padding контейнера.

### 3. Улучшение визуала карточек

Добавить свойство `borderColor` в `BlockStyles`, чтобы карточки могли иметь видимые рамки. Обновить рендер `card` блока — добавить полупрозрачную рамку по умолчанию.

### 4. Улучшение рендера формы

Сделать поля формы более реалистичными — добавить фокус-стиль, лучшие отступы, hover на кнопку.

### 5. Обновление block examples

Обновить стили в `BLOCK_EXAMPLES` — заменить устаревшие `#1a1a1a` карточки на стилизованные варианты с тенями и рамками.

### Логика группировки (ключевое изменение)

Перед рендером блоков, проход по массиву для определения "групп":

```text
[counter, counter, counter, heading, icon-text, icon-text, text]
     |--- группа 1 ---|              |-- группа 2 --|
```

Группа из 2+ блоков одного типа (counter, icon-text) оборачивается в CSS Grid:
- 2 блока -> `grid-cols-2`  
- 3 блока -> `grid-cols-3`
- 4+ блоков -> `grid-cols-4` (или `grid-cols-2` на мобильных)

### Полноширинные изображения

Для image-блоков с `padding: '0px'` и `borderRadius: '0px'`:

```text
margin: 0 -24px (компенсация padding канваса)
width: calc(100% + 48px)
```
