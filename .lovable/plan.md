## Что меняем

В карточке «Подписать готовый PDF» добавляем **ручное позиционирование** подписи и печати — после загрузки PDF можно мышкой/пальцем перетащить их туда, куда нужно, и только потом скачать.

## Как это будет выглядеть

```text
┌─ Подписать готовый PDF ──────────────────────────┐
│  [⇪ Перетащите PDF]  [Выбрать файл]              │
│                                                  │
│  ── после загрузки ──                            │
│  Страница: [‹] 1 / 3 [›]   [Сбросить позицию]    │
│  ┌────────────────────────────────┐              │
│  │                                │              │
│  │   превью страницы PDF          │              │
│  │                                │              │
│  │        ╭───────────╮           │              │
│  │        │ подпись   │ ← drag    │              │
│  │        ╰───────────╯           │              │
│  │        ╭───────╮               │              │
│  │        │ печать│   ← drag      │              │
│  │        ╰───────╯               │              │
│  └────────────────────────────────┘              │
│                                                  │
│  [Скачать подписанный PDF]                       │
└──────────────────────────────────────────────────┘
```

- Авто-распознавание «М.П.» остаётся — оно лишь выставляет **начальную** позицию подписи и печати. Дальше всё руками.
- На превью страницы лежат две перетаскиваемые «плашки»: полупрозрачное изображение подписи и печати (реальные PNG-ки из `document-images.ts`).
- Тащим мышкой (desktop) или пальцем (touch). Позиция сохраняется на каждую страницу отдельно.
- Кнопки: переключение страниц, «Сбросить позицию» (вернуть к авто-якорю), «Скачать PDF».
- Финальный PDF пересобирается через pdf-lib с координатами, которые задал пользователь.

## Технически

- Превью страницы рендерим через `pdfjs-dist` в `<canvas>` (или `<img>` из dataURL canvas-а), масштаб подгоняем под ширину карточки (например 600 px). Запоминаем `scale` = `pdfPagePoints / canvasPx`, чтобы переводить пиксели драга обратно в PDF-координаты при сохранении.
- Перетаскивание реализуем без библиотек: `pointerdown` / `pointermove` / `pointerup` на двух абсолютно спозиционированных `<div>` поверх canvas. Позиция хранится в state как `{ pageIndex: { sigX, sigY, stampX, stampY } }` в **точках PDF**.
- При смене страницы перерисовываем canvas и подставляем сохранённые координаты для этой страницы. Если для страницы координат нет — берём авто-якорь (`findStampAnchors`) или дефолт «низ-лево».
- При генерации финального PDF идём по всем страницам, для каждой берём её координаты и через `pdf-lib` рисуем подпись и печать (та же логика, что сейчас в `signPdf`, но с пользовательскими координатами вместо автоматических).
- Размеры подписи/печати оставляем фиксированными (как сейчас: подпись ~160×?, печать ~140×?). При желании можно потом добавить ресайз — но в этой итерации **только перемещение**.

## Файлы

- `src/lib/pdf-signer.ts` — рефакторим:
  - выносим утилиту рендера страницы в canvas: `renderPageToDataUrl(file, pageIndex, targetWidth)` → `{ dataUrl, pageWidthPt, pageHeightPt, scale, numPages }`.
  - меняем `signPdf` на `signPdfWithPlacements(file, placements: Record<pageIndex, { sigXPt, sigYPt, stampXPt, stampYPt }>)`.
  - оставляем `findStampAnchors` для расчёта стартовых позиций.
- `src/components/admin/SignPdfCard.tsx` — переписываем UI: загрузка → превью + drag → скачать. Убираем «Превью» отдельной кнопкой (превью теперь всегда видно).

## Что НЕ делаем

- Без ресайза/поворота подписи/печати (только move).
- Без сохранения позиций между сессиями — каждый новый файл начинает с авто-якоря.
- Без OCR для скан-PDF (как и было).
