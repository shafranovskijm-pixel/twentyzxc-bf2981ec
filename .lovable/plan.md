# PDF: тихое автосохранение и письма с вложениями

## 1. Кнопка «Скачать PDF» — подтверждение сохранения

Сейчас при клике уже вызывается `saveDocumentToDB`, который сохраняет договор в БД, создаёт контракт/клиента и загружает PDF в Storage (папка контракта). Оставим эту логику, но:

- сделаем сохранение **гарантированным до скачивания** (await цепочка уже есть);
- toast «Документ сохранён в базе» останется, плюс «PDF скачан».

Так пользователь видит явное подтверждение, что файл уже в карточке контракта.

## 2. Письмо — реальные PDF во вложении вместо ссылок

Сейчас функция `sendDocumentEmail`:
1. Генерит PDF (договор и счёт);
2. Загружает оба файла в Supabase Storage;
3. Получает signed URL на 7 дней;
4. Шлёт письмо со ссылками-кнопками.

Меняем шаги 3–4. Загрузка в Storage остаётся (нужна для архива контракта и истории), но **в письмо вкладываем сами PDF**.

Реализация:

- Удаляем создание signed URL и блок HTML с кнопками «Скачать ... (PDF)».
- Формируем массив `attachments`:
  ```
  [
    { filename: "Договор_001-2026_2026-05-19.pdf", base64: pdfBase64, contentType: "application/pdf" },
    { filename: "Счёт_001-2026_2026-05-19.pdf", base64: invoicePdfBase64, contentType: "application/pdf" }, // если есть
  ]
  ```
- В теле письма пишем: «Документ(ы) во вложении».
- Передаём `attachments` в `supabase.functions.invoke('send-document-email', ...)` — edge-функция уже поддерживает это поле (`multipart/mixed`).

Прогресс-бар:
- 35% «Прикрепление файлов» вместо «Сохранение в файлы»;
- блоки про signed URL убираем.
