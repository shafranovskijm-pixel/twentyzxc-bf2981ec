# Добавить готовое ТЗ «АЛИСТА» в раздел «ТЗ»

Цель: чтобы в новой вкладке «Технические задания» сразу было то самое ТЗ из PDF (Договор №253/2026, ООО «АЛИСТА»), его можно было открыть, отредактировать через мастер и скачать в Word/PDF.

## Что увидит пользователь

1. В разделе «ТЗ» появится первая запись — `ТЗ №253/2026 — ООО «АЛИСТА»`.
2. Действия в строке: «Открыть» (предпросмотр), «Редактировать» (мастер с уже заполненными данными и галочками), «Скачать PDF», «Скачать Word», «Удалить».
3. В мастере при редактировании:
   - Шаг 1 — реквизиты заказчика (ООО «АЛИСТА», ИНН 2543194698) уже подставлены.
   - Шаг 2 — параметры проекта: договор №253/2026 от 13.05.2026, сумма 55 000 ₽, срок 10 рабочих дней, сфера «Импорт авто/товаров».
   - Шаг 3 — чек-лист с уже отмеченными пунктами по всем разделам ТЗ из PDF (Цели, Структура сайта, Формы, Админка, CRM, Директ, Этапы, Обязанности заказчика, Приёмка, Гарантии).
   - Шаг 4 — предпросмотр и кнопки «Скачать PDF» / «Скачать Word».
4. Любые правки сохраняются — это полноценный документ, а не «зашитый» шаблон.

## Что делаем технически

1. **Сидинг записи в `tz_documents`** через миграцию (idempotent — `ON CONFLICT (tz_number) DO NOTHING`):
   - `tz_number = '253/2026'`, `tz_date = 2026-05-13`
   - `client_name = 'ООО «АЛИСТА»'`, `client_inn = '2543194698'`
   - `title = 'Разработка веб-сайта с функциями CRM, настройка Яндекс.Директ, администрирование'`
   - `payload jsonb` — структура `TzPayload` со всеми разделами PDF, разложенными по `sections[]` как чек-лист с `checked: true` и развёрнутыми `customNote` для прозы (карта страниц, формы, описание модулей CRM, этапы, обязанности заказчика и т.д.).
   - `template_id` не привязываем (свободная запись), `contract_id = null` (договора в БД нет — реквизиты лежат прямо в payload).
2. **Файлов кода менять не нужно** — `TzTab` уже умеет:
   - открывать запись на редактирование (предзаполняет мастер из `payload`),
   - экспортировать в Word через `exportTzDocx` (пакет `docx` уже установлен),
   - экспортировать в PDF через `exportTzPdf`.
3. **Проверка**: после миграции запись появится в списке без рефреша (react-query инвалидируется при действиях; при первом заходе данные подтянутся автоматически).

## Технические детали

- Миграция: один `INSERT` в `public.tz_documents` с собранным `jsonb`-payload. Никаких изменений схемы.
- Структура `payload.sections` соответствует существующему `TzSection`: `{ id, title, enabled: true, customNote, items: [{id, label, checked: true}] }`.
- Разделы (10 шт.): `goals`, `tech-stack`, `pages`, `forms`, `admin`, `crm`, `analytics`, `ads`, `stages`, `client-duties`, `acceptance`, `warranty`.
- Word-экспорт уже работает (`src/lib/tz/render.ts → exportTzDocx`), отдельных правок не требует.
