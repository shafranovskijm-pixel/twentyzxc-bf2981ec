

# Улучшения конструктора и шаблонов

## Часть 1: Инструменты конструктора

### 1.1 Дублирование проекта
Кнопка "Дублировать" в тулбаре -- создает копию текущего проекта с новым slug (добавляет суффикс `-copy`). Открывает диалог SaveDialog для ввода нового slug.

### 1.2 Импорт проекта из JSON
Кнопка "Импорт" рядом с экспортом HTML. Принимает JSON-файл (формат exportData), загружает блоки и настройки. Дополняет функцию `exportData` кнопкой "Скачать JSON".

### 1.3 Пользовательские цвета
Кнопка "+" рядом с пресетами цветов в BlockEditor. Сохраняет текущий цвет в localStorage. Отображает пользовательские цвета отдельной строкой с возможностью удаления.

### 1.4 Скрытие/показ блоков
В LayerList добавить иконку "глаз" для каждого блока. Скрытые блоки не рендерятся на канвасе и в экспорте, но остаются в списке. Новое поле `hidden?: boolean` в PlaygroundBlock.

### 1.5 SEO-настройки для опубликованных проектов
Поля title, description в настройках проекта (новый AccordionItem "SEO"). Сохраняются в таблице `playground_projects` (новые колонки `seo_title`, `seo_description`). Применяются через Helmet на странице `/p/:slug`.

- **SaaS/Pricing** -- Hero + фичи + табы с тарифами + FAQ (accordion) + CTA

Добавить примеры, демонстрирующие новые типы блоков:
- **FAQ секция** -- заголовок + аккордеон с 4-5 вопросами
- **Табы с контентом** -- заголовок + блок табов
- **Карточки команды** -- заголовок + колонки с фото и именами
- **Секция "Как это работает"** -- 3 icon-text блока с шагами

## Техническая реализация

### Изменения в базе данных
- Новые колонки в `playground_projects`: `seo_title TEXT`, `seo_description TEXT`

### Изменения в типах
- `PlaygroundBlock`: добавить `hidden?: boolean`
- `PlaygroundSettings`: добавить `seoTitle?: string`, `seoDescription?: string`

### Файлы для изменения
- `src/data/playground-effects.ts` -- новое поле hidden в PlaygroundBlock

- `src/components/playground/Canvas.tsx` -- фильтрация скрытых блоков
