# Скрытие упоминаний и быстрый новый договор

## Что делаем

1. **Убрать конкретное напоминание.** У каждой строки в «Активных упоминаниях» появляется кнопка-крестик «Скрыть». Скрытое упоминание пропадает из списка и перестаёт уходить в Telegram.
2. **Оформить новый договор.** У упоминаний типа «Срок услуги: … осталось N дн.» (и «Продление») рядом с «Договоры» появляется кнопка «Новый договор» — она открывает вкладку «Договоры» с сразу открытой формой создания и подставленным клиентом.
3. **Возврат скрытых.** В шапке карточки — счётчик скрытых и кнопка «Показать скрытые», чтобы вернуть ошибочно убранное.

## Логика скрытия

- Скрытие привязано к конкретному объекту (договор + тип уведомления, клиент + срок услуги), а не к типу целиком — остальные клиенты продолжают напоминать.
- Для «просрочена оплата» и «оплата истекает» скрытие автоматически снимается, если у договора изменится дата оплаты (`paid_until`) — то есть после продления оплаты напоминание вернётся уже по новому сроку.
- Для «срок услуги» скрытие снимается, если изменится дата окончания услуги у клиента.

## Технические детали

- Новый ключ в `site_settings`: `telegram_notifications_dismissed` — объект вида `{ "<item-key>": "<snapshot>" }`, где `item-key` = тип + id сущности, а `snapshot` — значение даты (`paid_until` / `service_deadline` / годовщина), при изменении которого скрытие считается недействительным.
- `src/hooks/use-notification-settings.tsx`: добавить чтение/запись карты скрытых (`dismissed`, `dismiss(key, snapshot)`, `restoreAll()`).
- `src/components/admin/NotificationsTab.tsx`: у каждого `Item` считать `dismissKey` и `snapshot`; фильтровать скрытые; кнопки «Скрыть» (X) и «Новый договор» для типов `deadlines` и `renewals`; строка «Скрыто: N · Показать скрытые».
- `src/pages/Admin.tsx`: новый колбэк `onNewContract(clientName)` → переключение на вкладку договоров с `initialClientName` + `autoOpenNew` (эти пропсы у `ContractsTab` уже есть).
- `supabase/functions/_shared/notification-settings.ts`: добавить загрузку карты скрытых и хелпер `isDismissed(key, snapshot)`.
- `supabase/functions/check-overdue/index.ts` и `send-scheduled-reminders/index.ts`: пропускать скрытые позиции по тем же ключам, чтобы бот их не слал.
