

## План: Развернуть планер на всё доступное пространство

### Проблема
Колонки дней слишком узкие (min-w-[160px]), не растягиваются на всю ширину. Карточки задач мелкие, много пустого пространства внизу не используется.

### Решения

**1. Колонки на всю ширину**
- Убрать `overflow-x-auto` с контейнера колонок, заменить на `grid grid-cols-7` с равной шириной
- Колонки автоматически займут всё доступное пространство
- Убрать `min-w-[160px]` и `flex-1` — грид сам распределит

**2. Высота на весь экран**
- Контейнер планера: `h-[calc(100vh-12rem)]` чтобы занять всё вертикальное пространство
- Колонки дней: `flex-1` по высоте с `overflow-y-auto` для скролла задач
- Область задач внутри дня: `min-h-[200px]` вместо `min-h-[120px]`

**3. Карточки задач крупнее**
- Padding карточки: `p-3` вместо `p-2`
- Текст задачи: `text-sm` → `text-base`
- Бейджи статуса: `text-xs` вместо `text-[10px]`
- Иконка drag: `h-4 w-4` вместо `h-3 w-3`

**4. Шапка дня крупнее**
- Номер дня: `text-xl font-bold` вместо `text-lg`
- День недели: `text-sm` вместо `text-xs`
