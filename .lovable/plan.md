## Пустые графы со стороны заказчика в акте сверки

В шаблоне `src/lib/reconciliation-template.ts` правая половина таблицы «По данным [клиента]» сейчас зеркалит наши данные. Нужно её оставить пустой, чтобы контрагент сам заполнил.

### Изменения в `src/lib/reconciliation-template.ts`

1. **Строки операций (`rowsHtml`)** — справа 4 пустые ячейки (`<td>&nbsp;</td>` × 4) вместо зеркала.
2. **Сальдо начальное** — правая ячейка `colspan="4"` остаётся пустой (без подписи).
3. **Обороты за период** — правая половина: `<td colspan="2">Обороты за период</td><td></td><td></td>` (без чисел).
4. **Сальдо конечное** — правая половина: подпись + две пустые ячейки.
5. **Блок выводов внизу** (`.summary`) — правый блок «По данным [клиента]»: вместо вывода с суммой — пустая строка с подчёркиванием для ручного заполнения, например:
   `на ____________ задолженность в пользу ____________________ ______________ руб. ( _____________________________________ ).`
6. **Подпись клиента** — уже есть пустая строка для имени, оставляем как есть.

Высота строк не меняется — пустые `<td>` сохранят разметку, просто будут белыми.
