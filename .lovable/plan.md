## Что не работает сейчас

Edge-функция `parse-rosobrnadzor` стучится в `isga.obrnadzor.gov.ru/api/v1/search` — у Рособрнадзора **нет публичного JSON-API**. Это SPA-портал, поэтому запросы висят до таймаута. Открытые данные публикуются как **дамп** (ZIP/XLSX/JSON) на `opendata.obrnadzor.gov.ru` — реестр лицензий вузов/доп. образования.

## Новая архитектура парсера

Разделяем на 2 функции:

### A. `import-rosobrnadzor-dump` (фоновая, разовая + по cron раз в неделю)
- Скачивает официальный дамп реестра лицензий (`opendata.obrnadzor.gov.ru` → файл `data-*.xlsx` или `.json`).
- Парсит, кладёт в `rosobrnadzor_licenses` (PK = ИНН).
- Будет ~150–300 тыс. записей. Заливаем батчами по 500. Один прогон — пара минут.
- Вызов из UI: кнопка «Обновить реестр» в SalesTab (видна только в первый раз / при необходимости).

### B. `enrich-lead` (быстрая, синхронная — при добавлении лида)
Принимает `{ inn?, name? }`. Делает параллельно:
1. **DaData** `findById/party` (по ИНН) **или** `suggest/party` (по названию, top 5) — название, КПП, ОГРН, адрес, иногда email/телефон, ФИО руководителя.
2. **Локальный кэш** `rosobrnadzor_licenses` по ИНН — номер/дата/статус лицензии, ссылка на запись в реестре.

Возвращает объединённый объект. Быстро, без походов на сайт Рособрнадзора в реальном времени.

## UI: умное добавление лида

В диалоге «Новый лид»:
- Поле «Организация» превращаем в **поиск с подсказками DaData** (по мере ввода — список похожих организаций с ИНН и адресом). Выбор подсказки заполняет всё: название, ИНН, адрес, КПП, ОГРН, директора, email/телефон (если есть).
- Альтернатива: ввести ИНН → кнопка «🔍 Найти» рядом → автозаполнение тем же `enrich-lead`.
- Если у организации найдена лицензия Рособрнадзора — сразу показываем бейдж «Лицензия № … от …» в диалоге.

Кнопка «Сохранить» — как сейчас.

В таблице действие «Подтянуть по ИНН» (⋮) использует тот же `enrich-lead`.

## Тест

После реализации:
1. Жму «Обновить реестр» → жду индексации (toast с прогрессом).
2. «+ Добавить» → ввожу ИНН вуза, например `7706074737` (Финансовый университет) → видим автоподстановку названия/адреса + бейдж лицензии.
