## Что добавляем

Новый тип документа — **Акт сверки взаимных расчётов** — на основе вашего CRM (договоры + платежи) с возможностью ручной правки строк (как в загруженном PDF от ЭЛАР КЛИНИК).

## Как это будет работать

1. В админке во вкладке **Документы** в селекторе типа добавится 4-й вариант: **«Акт сверки»**.
2. Выбираете клиента → период (например, Янв 2024 – Апр 2026) → система автоматически подтягивает:
   - все `contracts` клиента в периоде (как «Дебет» — начисления);
   - все ваши пометки об оплатах (как «Кредит»).
3. Можно **вручную править/добавлять/удалять строки** прямо в таблице (Дата | Документ | Дебет | Кредит) — для случаев, когда в CRM нет каких-то платежей.
4. Автоматически считается:
   - Обороты за период
   - Сальдо конечное
   - Сумма прописью
   - Фраза «задолженность в пользу …»
5. Документ сохраняется в `generated_documents` с `doc_type = 'reconciliation'`, нумерация `NNN/YYYY` (как у остальных), доступен в Истории.
6. Можно: предпросмотр → печать/PDF → отправка в Telegram → отправка на email клиента (как и для других документов).

## Шаблон документа

Один-в-один по структуре вашего PDF:
- Заголовок «Акт сверки взаимных расчётов за период …»
- Между «Исполнитель (ваши реквизиты из site_settings)» и «Заказчик (clients.name + ИНН)»
- Двухколоночная таблица «По данным Исполнителя | По данным Заказчика» (зеркальная — Дебет ↔ Кредит)
- Строка «Сальдо начальное» / «Обороты за период» / «Сальдо конечное»
- Подпись + печать слева (ваши `signature.png` + `stamp.png`), справа — пустое поле для контрагента
- Сумма задолженности прописью

## Конкретно для ЭЛАР КЛИНИК (по вашему PDF)

После реализации:
- открываете «Документы» → «Акт сверки» → клиент **ЭЛАР КЛИНИК**
- период: 01.01.2024 – 30.04.2026
- в таблицу попадают 3 платежа: 18 000 (19.08.24) + 18 000 (13.06.25) + 35 000 (16.04.26) = 71 000
- в части «Дебет» (начисления) сумма тоже будет 71 000 (по актам, которые вы уже выставляли)
- сальдо конечное = 0 ⇒ задолженность = 0 (либо 35 000 по последнему неактированному договору — это уже выставите вручную в строках)

## Технические детали

- **Файл шаблона**: новый `src/lib/reconciliation-template.ts` — функция `generateReconciliationHtml(data)` с двухколоночной таблицей.
- **DocumentsTab.tsx**: расширить тип `DocType = "contract" | "invoice" | "act" | "reconciliation"`; добавить UI-блок (период from/to + редактируемая таблица строк); ветка превью.
- **Автонумерация**: переиспользовать существующую логику (`%/YYYY` фильтр) — счётчик отдельный по `doc_type='reconciliation'`.
- **БД**: схема `generated_documents` уже подходит (`services jsonb` хранит строки, `metadata` — период и сальдо). Миграция не нужна.
- **История/Email/Telegram**: работают «из коробки» — там код общий по `doc_type`.
- **Отдельная вкладка «Акты сверки»**: НЕ делаю — лишний шум в сайдбаре. Всё внутри «Документы», фильтр по типу в Истории уже есть. Если хотите отдельную вкладку — скажите, добавлю в 5 минут.

## Что НЕ входит

- Автоподтягивание дат и сумм оплат из банковской выписки (у вас в CRM нет платежей по датам — только `payment_date` и `amount` на договоре). Будем брать `contract.payment_date` + `contract.amount` для строк «оплата». Если нужна полноценная книга платежей — это отдельная задача.
