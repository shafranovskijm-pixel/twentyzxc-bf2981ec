

## Plan: Лендинг-шаблоны для клиентов — 5 универсальных одностраничников

### Контекст

Сейчас в каталоге 12 шаблонов (3 лендинга, 3 корпоративных, 3 e-commerce, 3 webapp). Нужно добавить 5 новых лендинг-шаблонов, ориентированных на услуги — чтобы клиентам CRM можно было быстро собирать одностраничники. Референс — атмосферный «ЛЕС» (token-harmony-play).

### 5 новых лендингов

Каждый шаблон — полноценный Preview-компонент с обязательными секциями продающего лендинга:

| # | Название | Стиль | Ниша |
|---|----------|-------|------|
| 1 | **Nature Flow** | Мягкие градиенты, зелень, органика, как «ЛЕС» | Велнес, экология, натуральные продукты |
| 2 | **Urban Pulse** | Тёмный, индустриальный, городской ритм | Рестораны, бары, фитнес, event |
| 3 | **Clean Studio** | Белый, светлый, воздушный минимализм | Салоны красоты, студии, медицина |
| 4 | **Neon Drive** | Яркие неоновые акценты на тёмном фоне | IT-услуги, геймдев, маркетинг |
| 5 | **Warm Craft** | Тёплые тона, крафтовая эстетика, текстуры | Мастерские, кофейни, фотографы |

### Обязательные секции каждого лендинга

Проверенная структура для конверсии:

```text
1. Hero — заголовок + подзаголовок + CTA кнопка + фон/изображение
2. Преимущества — 3-4 карточки с иконками
3. О нас / История — текст + изображение
4. Услуги / Тарифы — 2-3 плана с ценами и CTA
5. Отзывы — карусель с аватарами
6. FAQ — аккордеон с вопросами
7. Контакты / CTA — форма заявки + телефон/email/карта
8. Футер — логотип, навигация, соцсети
```

### Реализация

**Файлы:**
- **`src/data/templates.ts`** — добавить 5 записей в категорию `landing`
- **5 новых Preview-компонентов** в `src/components/templates/previews/unique/`:
  - `NatureFlowPreview.tsx`
  - `UrbanPulsePreview.tsx`
  - `CleanStudioPreview.tsx`
  - `NeonDrivePreview.tsx`
  - `WarmCraftPreview.tsx`
- **`src/components/templates/previews/unique/index.ts`** — экспорт новых компонентов
- **`src/pages/TemplatePreview.tsx`** — подключить новые превью к роутингу

Каждый компонент ~300-400 строк, с анимациями (Framer Motion), каруселью отзывов (Embla), аккордеоном FAQ, адаптивом. Стилизация уникальная под каждую нишу.

### Будущие расширения (не в этом плане)

- Касса (оплата за шаблоны)
- Личный кабинет клиента (редактирование контента лендинга)
- Привязка лендинга к домену клиента
- Взаиморасчёты через CRM
