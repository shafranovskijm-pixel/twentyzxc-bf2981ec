

# Улучшение готовых шаблонов страниц

## Проблемы текущих шаблонов

Сейчас шаблоны выглядят как набор отдельных блоков с одинаковыми отступами и однотипной стилизацией `#141418`. У них нет:
- **Секционного разделения** -- все блоки идут сплошным потоком без визуального разделения секций
- **Контрастных секций** -- нет чередования тёмных и чуть более светлых секций (как на настоящих сайтах)
- **Полноширинных hero-изображений** с оверлеем и текстом поверх
- **Градиентных фоновых переходов** между секциями
- **Реалистичного футера** -- сейчас минимальный однострочный
- **Визуальных разделителей** между секциями
- **Уникальности** -- все 15 шаблонов используют одну и ту же тёмную палитру `#141418` для карточек

## План улучшений

### 1. Переработка PAGE_TEMPLATES (все 15 шаблонов)

Каждый шаблон получит:

**a) Контрастные секции** -- чередование фона секций через spacer + card с разными оттенками фона. Например, чередование `#0a0a0a` и `#111111` создаёт ощущение реальных секций сайта.

**b) Уникальные цветовые палитры** -- каждый шаблон использует свою палитру:
- Визитка: тёмно-синий (#0d1b2a, #1e293b, #94a3b8)
- Лендинг: чёрный + зелёный (#0a0a0a, #111111, #22c55e) 
- Портфолио: тёмный + фиолетовый (#0f0f1a, #1a1a2e, #a855f7)
- Промо: чёрный + красный (#0a0a0a, #1a1111, #ef4444)
- Ресторан: тёплый коричневый (#1a1510, #2a1f14, #c9a55a)
- и т.д.

**c) Больше контента** -- шаблоны станут длиннее и реалистичнее:
- Hero секция с большим заголовком и подзаголовком
- Секция преимуществ (3-4 карточки)
- Секция "О нас" или социальное доказательство
- CTA секция
- Развёрнутый футер

**d) Более продуманные стили блоков**:
- Заголовки секций с уникальными градиентами
- Кнопки с соответствующими стилями (gradient для главных CTA, outline для вторичных)
- Карточки с тонкими бордерами, тенями и hover-эффектами
- Формы с тематической стилизацией

### 2. Улучшение SECTION_TEMPLATES (готовые секции)

Текущие 7 секций слишком простые. Каждая будет расширена:

- **Hero с CTA** -- добавить декоративный текст-лейбл сверху ("НОВИНКА 2026"), более крупный заголовок с градиентом, подзаголовок, две кнопки (основная + вторичная)
- **Блок преимуществ** -- добавить подзаголовок секции, сделать 4 карточки вместо 3
- **Отзывы** -- добавить звёздочки, аватарки (эмодзи), фоновые карточки с разными оттенками
- **CTA-баннер** -- сделать полноценный баннер с градиентным фоном и двумя кнопками
- **FAQ секция** -- добавить контактный текст внизу ("Не нашли ответ? Напишите нам")
- **Тарифы** -- выделить "популярный" тариф визуально (другой цвет бордера, бейдж)
- **Статистика** -- добавить заголовок секции и подзаголовок

### 3. Новые готовые секции

Добавить 5 новых секций:
- **Логотипы партнёров** -- текст "Нам доверяют" + ряд логотипов-заглушек
- **Процесс работы** -- 4 шага с нумерацией и стрелками
- **Контакты** -- карта (заглушка) + email/телефон + форма
- **Hero с изображением** -- заголовок слева + картинка справа (через columns)
- **Баннер с обратным отсчётом** -- акция с таймером

## Технические детали

### Файлы для изменения

**`src/components/playground/ProjectTemplates.tsx`**:
- Обновить массив `PAGE_TEMPLATES` -- переработать все 15 шаблонов с более детальной стилизацией, контрастными секциями и уникальными палитрами
- Обновить массив `SECTION_TEMPLATES` -- расширить существующие 7 и добавить 5 новых секций
- Каждый шаблон станет длиннее (15-20 блоков вместо 10-12), но визуально будет разбит на логические секции

### Принципы стилизации

Для каждого шаблона:
1. Navbar с backdrop-blur и полупрозрачным фоном
2. Hero секция -- крупный заголовок с градиентом, подзаголовок приглушённым цветом, 1-2 кнопки
3. Секция с карточками -- контрастный фон (чуть светлее/темнее основного), карточки с тенями и бордерами
4. Социальное доказательство -- счётчики, отзывы или логотипы
5. CTA секция -- яркий акцент, gradient-кнопка
6. Футер -- тёмный фон, несколько колонок информации

Все стили задаются через `BlockStyles` -- никаких новых типов блоков не требуется.
