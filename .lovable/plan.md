
# Примеры блоков -- группировка по типам в аккордеон

## Что изменится

Секция "Примеры блоков" в левом сайдбаре конструктора сейчас показывает плоскую сетку из ~15 примеров. Вместо этого при раскрытии "Примеры блоков" появится вложенный аккордеон с категориями:

```text
v Примеры блоков
  > Структура сайта (3 примера: Меню навигации, Футер, Колонки "3 шага")
  > Контент (4 примера: Герой-заголовок, Преимущества, FAQ карточка, YouTube видео)
  > Статистика и акции (3 примера: Статистика, Таймер акции, Отзыв клиента)
  > Визуал и галереи (3 примера: Галерея 2 фото, Галерея 6 фото, CTA секция)
  > Бизнес (3 примера: Ценовая карточка, Команда, Форма заявки)
```

Каждая категория раскрывается и показывает 3-6 примеров в сетке 2 колонки (как сейчас), с иконками и описаниями.

## Технические детали

### Файл: `src/components/playground/ProjectTemplates.tsx`

1. Добавить массив категорий `BLOCK_EXAMPLE_CATEGORIES` -- каждая категория содержит название, иконку и массив id примеров из существующего `BLOCK_EXAMPLES`.
2. Также добавить 2 новых примера для наполнения категорий (форма заявки + соцсети), чтобы в каждой было 3-6 штук.
3. Переписать компонент `BlockExamplesList` -- вместо плоского grid использовать `Accordion` из `@radix-ui/react-accordion` с вложенными категориями. Каждая категория раскрывается и показывает grid с примерами.

### Файл: `src/pages/Playground.tsx`

Никаких изменений не потребуется -- `BlockExamplesList` используется как есть, интерфейс props не меняется.

### Визуальный стиль
- Вложенный аккордеон будет компактнее родительского (меньший padding, мелкий шрифт триггера)
- Иконки категорий золотого цвета для акцента
- При первом открытии все категории свернуты
