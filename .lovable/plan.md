

## План: Ускорение загрузки админ-панели + два пароля ФРДО (ДПО/ПО)

### Проблема 1: Медленная загрузка

Сейчас при открытии админ-панели происходит блокирующая загрузка `site_settings` (строка 176 в Admin.tsx — пока настройки не загрузятся, показывается спиннер), даже если пользователь идёт в раздел «Клиенты» или «Договоры», где эти настройки не нужны.

**Решение:**
- Убрать блокировку загрузки по `settingsLoading` из общего лоадера — показывать панель сразу после проверки авторизации
- Загружать `site_settings` только когда пользователь открывает раздел SEO/Контакты (ленивая загрузка)
- Добавить `staleTime` к тяжёлым запросам (clients, contracts, files), чтобы при переключении вкладок данные не перезапрашивались каждый раз

### Проблема 2: Один пароль ФРДО вместо двух

В таблице `clients` есть только `frdo_password`. Нужно добавить второе поле `frdo_password_po` для пароля ПО, а текущее поле переименовать в интерфейсе как «Пароль ДПО».

**Решение:**

1. **Миграция БД** — добавить колонку `frdo_password_po TEXT` в таблицу `clients`

2. **ClientsTab.tsx** — обновить:
   - Добавить state `frdoPasswordPo`
   - Изменить форму: вместо одной строки с логином и паролем — строка с логином, затем строка с двумя паролями (ДПО и ПО)
   - Обновить `saveClient`, `startEdit`, `resetForm` для нового поля
   - Обновить интерфейс `Client`

### Файлы для изменения

| Файл | Что меняется |
|---|---|
| Миграция SQL | `ALTER TABLE clients ADD COLUMN frdo_password_po TEXT` |
| `src/components/admin/ClientsTab.tsx` | Новое поле формы, state, сохранение |
| `src/pages/Admin.tsx` | Убрать блокировку по settingsLoading |
