

# Живой таймер и улучшение визуала шаблонов

## Проблема 1: Таймер показывает сырую дату

Сейчас блок `countdown` просто выводит строку `2026-09-15T15:00:00` как текст. Нужен живой обратный отсчёт с красивым отображением дней, часов, минут и секунд.

### Решение

Создать компонент `CountdownTimer`, который:
- Парсит дату из `content` (формат `ISO-дата|Подпись`)
- Использует `setInterval` (каждую секунду) для подсчёта оставшегося времени
- Отображает карточки: **дни**, **часы**, **минуты**, **секунды**
- Показывает "Время вышло!" если дата прошла
- Стилизация: отдельные блоки для каждой единицы с полупрозрачным фоном и подписями ("дн", "ч", "мин", "с")

Обновить рендеринг `countdown` в трёх файлах:
- `src/components/playground/Canvas.tsx` -- в редакторе
- `src/pages/PlaygroundView.tsx` -- на опубликованной странице
- `src/lib/export-html.ts` -- в экспорте HTML (статический снимок + JS-логика)

## Проблема 2: Шаблоны выглядят однообразно

Все шаблоны используют одинаковый стиль: прозрачный фон, белый текст, стандартные отступы. Нужна уникальная визуальная идентичность для каждого шаблона.

### Решение

Улучшить существующие шаблоны, добавив:

**Визитка** -- Градиентный заголовок (золотой), декоративная рамка, тёмно-синий фон карточек

**Лендинг** -- Градиентный текст заголовка, акцентные карточки с цветными левыми бордерами, больше контраста

**Портфолио** -- Фоновые карточки с hover-свечением, градиентная подпись

**Промо** -- Пульсирующий градиент на скидке, яркие акцентные цвета

**Резюме** -- Тёмные карточки навыков с акцентными бордерами, стильные счётчики

**Ресторан** -- Тёплая палитра (#2a1f14 фон карточек), декоративные разделители

**Событие** -- Яркие счётчики с фоном, акцентные карточки программы

**Стартап** -- Градиентный CTA, карточки фичей с иконками-акцентами

**Фитнес** -- Энергичные цвета (красный/оранжевый акценты), тёмные мощные карточки

**Свадьба** -- Мягкая палитра (розовый/золотой), элегантные шрифты, нежные фоны карточек

**Недвижимость** -- Строгая палитра (тёмно-синий), карточки с тенями, акцентные цены

**SaaS** -- Современный стиль с фиолетовыми/синими градиентами, чёткие карточки тарифов

### Конкретные улучшения для каждого шаблона

Для каждого шаблона обновить:
- `backgroundColor` карточек и секций -- уникальные оттенки вместо `#1a1a1a`
- `textColor` -- разнообразие акцентных цветов вместо одинакового `#d4a855`
- `gradientText` -- добавить градиенты для заголовков
- `boxShadow` -- добавить тени для глубины
- `hoverEffect` -- разнообразить hover-эффекты
- Добавить `spacer` блоки для лучшего дыхания контента
- Увеличить разнообразие анимаций
