

## План: Редизайн карточки «Синтагма» в стиле сайта sintagma.com.ru

### Что не нравится сейчас
- Шрифт `Playfair Display` (золотая курсивная классика) выглядит «устаревше» на фоне современного минимализма реального сайта Синтагмы
- Бейдж `FLAGSHIP PROJECT` (мелкий каприз, золотой italic) — лишний и не в стилистике бренда
- Двойной слой `gradient-gold-text` + `shimmer` создаёт перегруженный «нулевой» эффект
- Огромная фоновая буква `S` в углу — декоративный шум

### Что есть на реальном сайте Синтагмы (по скриншоту)
- **Логотип + лого-марка**: тёмная плашка с символом Σ + жирный гротеск «СИНТАГМА» (трекинг ~0.15em)
- **Заголовки**: современный высококонтрастный serif (близкий к **PT Serif** / **Source Serif** / **Lora**)
- **Бирюзово-мятный акцент** (#3DD0B6 ~) под заголовком
- **Чистый воздух**, мягкие тени, никакого золотого глянца

### Решение

**1. Обновлённая карточка `SyntagmaCard`:**
- Убираю фоновую `S`, убираю двойной shimmer
- Заменяю «FLAGSHIP PROJECT» italic-капс на **минималистичный лого-блок**: тёмный квадрат с символом **Σ** + плотный uppercase «СИНТАГМА» (как на их сайте) + тонкая мятная подпись «Облачная LMS-платформа»
- Заголовок «Синтагма» меняю на новый visual: вместо большого golden-gradient слова — **средний elegantный serif заголовок** + маленькая мятная декоративная полоска под ним (как индикатор слайдера у них на сайте)
- Описание — тот же текст, но через `font-sans` (Inter) для воздуха
- 3 фичи остаются, но иконки на чуть более мягкие (мятный hover-акцент вместо чисто золотого)
- CTA «Подробнее о проекте» — приглушённый тёмный pill-button (как у них), а не яркий gold

**2. Новый шрифт для serif-акцентов на карточке:**
- Подключаю **Source Serif 4** (через Google Fonts) — современная elegance, ровно как на их сайте
- Создаю tailwind-класс `font-syntagma` (только для этой карточки, чтобы не ломать остальной сайт где Playfair работает хорошо)
- Тег «СИНТАГМА» внутри лого — **Inter Tight 700 uppercase** с трекингом

**3. Визуальный акцент `mint`:**
- Добавляю CSS-переменную `--syntagma-accent: 167 60% 53%` (мягкий бирюзово-мятный)
- Используется только в этой карточке: тонкая полоска под заголовком, hover-стейт CTA, точка перед подписью
- Не конфликтует с глобальной gold-системой

**4. Что НЕ трогаю:**
- Класс `tropical-card` остаётся (стеклянная подложка вписывается)
- Расположение карточки в секции, ServiceCards ниже — без изменений
- Глобальные шрифты сайта (Playfair) — без изменений
- `synthetic_gates` achievement остаётся

### Файлы под изменение
- ✏️ `src/index.css` — добавить `@import` для Source Serif 4 + Inter Tight, CSS-переменная `--syntagma-accent`, класс `.font-syntagma`
- ✏️ `tailwind.config.ts` — добавить `syntagma` в fontFamily
- ✏️ `src/components/WebDevSection.tsx` — переписать `SyntagmaCard` (логотип-блок, новый serif-заголовок, мятный акцент, чистый CTA)
