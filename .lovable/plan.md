

## Диагностика: договор не появился

Я проверил базу данных — **за сегодня не было создано ни одного нового договора**. Все 115 записей имеют дату создания из миграции (03:02-03:03 UTC). Это значит, что при попытке создать новый договор он **не сохранился** в базу.

### Вероятная причина

Создание договора использует `supabase.from("contracts").insert(...)`, что требует активной admin-сессии. Если сессия истекла, вставка тихо проваливается или выбрасывает ошибку, которая может быть не видна пользователю.

### План исправления

1. **Добавить явную обработку ошибок при создании договора** — в `ContractsTab.tsx` (строка ~174) убедиться, что ошибка вставки показывается пользователю через toast, а не проглатывается.

2. **Добавить проверку сессии перед сохранением** — перед `insert` вызывать `supabase.auth.getSession()` и если сессии нет, показывать «Сессия истекла, войдите заново».

3. **Проверить кеш таблицы** — текущий порядок `updated_at DESC` применён, но кеш React Query может показывать старые данные. Добавить `refetchOnWindowFocus: true` в query options.

### Файлы для изменения

- **`src/components/admin/ContractsTab.tsx`**: добавить проверку сессии в `saveContract`, улучшить отображение ошибок, добавить `refetchOnWindowFocus`.
