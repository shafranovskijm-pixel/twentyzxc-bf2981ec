

## План: Кейсы вместо акций + тропический фон на 4 карточках услуг

### Часть 1. Тропический фон в 4 карточках (Лендинги / Корпоративные / Магазины / Веб-приложения)

Сейчас секция WebDev уже имеет общий нарисованный фон (закат с пальмами). Сами 4 карточки услуг используют класс `tropical-card` (тёмная стеклянная подложка) — фон ИИ-картинки внутри них пока нет.

**Что сделаю:**
- Сгенерирую через Lovable AI (Nano banana) **4 уникальные тропические мини-сцены** для фоновой подложки каждой карточки в едином стиле «нарисованный пиратский тропик»:
  1. **Лендинги** — закатный пляж с одинокой пальмой и волной
  2. **Корпоративные сайты** — три пальмы и каменная веранда (символ устойчивости)
  3. **Интернет-магазины** — рынок-навес у моря, корзины, бананы (торговля)
  4. **Веб-приложения** — пальмы и старинная астролябия / компас (сложные системы)
- Сохраню в `src/assets/card-bg-landing.jpg` … `card-bg-webapp.jpg`
- В `ServiceCard` добавлю `<img>` подложку с `opacity-25..35` + тёмный градиент сверху, чтобы текст и 3D-ключ оставались читаемыми
- Стиль карточек (`tropical-card`) и текущие 3D-ключи **не трогаю** — только подложка

### Часть 2. «Кейсы» вместо «Акций»

Заменяю секцию `PromotionSection` на новую секцию **«Кейсы»** (`CasesSection`), которая берёт реальные проекты из таблицы `portfolio_projects` (Supabase) и оформляет их как мини-кейсы с метриками/задача-решение-результат.

**Контент кейсов** (на базе реального портфолио — придуманные метрики в духе проектов):

| Кейс | Задача | Решение | Результат |
|---|---|---|---|
| **Синтагма (LMS)** | Автоматизировать выдачу удостоверений в учебном центре | Облачная LMS + интеграция с ФРДО | −80% ручной работы, 1000+ слушателей в месяц |
| **SpinRide** | Запустить продажи велосипедов и самокатов онлайн | Каталог 800+ позиций + Яндекс Директ + сезонные темы | Окупаемость рекламы за 2 месяца, 5000 ₽/мес поддержки |
| **Анна Чмулева (риелтор)** | Персональный бренд эксперта по недвижимости | Сайт + ИИ-помощник для блога + CRM заявок | Автоматизированный блог, рост входящих обращений |
| **Flowrish (цветы)** | Магазин с гибким сезонным оформлением | E-commerce + админка + 7 праздничных тем с авто-таймером | Продажи 24/7 без участия владельца |
| **УЦ «Статус»** | Сложный переезд + ФРДО + LMS | Полное сопровождение под ключ | Запуск без простоев, 65 000 ₽/год за всё |

(5 кейсов в карусели/сетке; каждый — карточка с тэгами, тремя строками З→Р→Р, ссылкой «Подробнее»)

**Дизайн карточек кейсов:**
- Тот же `tropical-card warm-card-glow`
- Слева — крупная цифра-метрика (`+250%`, `×3`, `−80%`) золотом
- Справа — заголовок проекта, локация, мини-разделы «Задача / Решение / Результат», теги
- Кнопка «Открыть кейс» → `url` проекта (внешний или `/projects/...`)
- Заголовок секции: **«Кейсы»** + подзаголовок «Реальные проекты — реальные результаты»
- Декор: пальмовые акценты, секция-якорь `id="cases"`

**Что с акциями:**
- Полностью убираю `PromotionSection` из `Index.tsx` и заменяю на `<CasesSection />`
- Сам файл `PromotionSection.tsx` оставляю (не удаляю — может вернуться), таблицу `promotions` тоже не трогаю
