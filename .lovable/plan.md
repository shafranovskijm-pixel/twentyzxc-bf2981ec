

## Проблема

Клиенты отсортированы по `created_at` (дате создания), а договоры — по `contract_number` (номеру). Последний клиент, с которым работали (например, «Арсенал»), не отображается вверху списка.

## Решение

Изменить сортировку на `updated_at DESC` в обоих табах, чтобы последний редактированный/взаимодействованный элемент всегда был вверху.

### Изменения

**`src/components/admin/ClientsTab.tsx`** (~строка 93):
- Заменить `.order("created_at", { ascending: false })` на `.order("updated_at", { ascending: false })`

**`src/components/admin/ContractsTab.tsx`** (~строка 60):
- Заменить `.order("contract_number", { ascending: false })` на `.order("updated_at", { ascending: false })`

Две строки — два файла. Клиент/договор, с которым последний раз взаимодействовали (редактировали, обновляли), будет всегда вверху списка.
