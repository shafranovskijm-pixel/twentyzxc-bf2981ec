
## Что делаем

Добавляем в панель Синтагмы (`/org`) новый раздел **«Продажи»** (лиды), открывающийся по умолчанию, с таблицей лидов как на скриншоте и рассылкой холодных писем по готовому шаблону.

## 1. Новый раздел «Продажи» (открывается первым)

В `OrgSidebar` первым пунктом ставим `sales` (иконка `TrendingUp`). В `OrgPanel` меняем initial `activeSection` на `"sales"`. Старые разделы остаются.

## 2. Таблица лидов

Поля (как на втором скрине):

| Организация | Сайт | Email / телефон | Откуда нашли | Статус | Следующий шаг |

Статусы: `Новый`, `Письмо отправлено`, `Ответ получен`, `Демо назначено`, `Договор`, `Отказ`.

Действия в строке: редактировать, удалить, **«Отправить письмо»** (кнопка с иконкой Mail).

Над таблицей: поиск по названию + фильтр по статусу + кнопка «+ Добавить лид» + кнопка «Импорт из Excel» (CSV/XLSX) с маппингом колонок.

## 3. База данных

Миграция — новая таблица `org_leads`:

```text
id uuid PK
organization_id uuid → organizations
name text                 (название организации-лида)
website text
email text
phone text
source text               (откуда нашли: ФРДО / Рособрнадзор / Яндекс / ...)
status text default 'new'
next_step text
notes text
last_email_sent_at timestamptz
created_at, updated_at
```

RLS: владелец организации видит/редактирует только свои лиды (через `user_id` владельца `organizations`). GRANT для `authenticated` + `service_role`.

## 4. Рассылка писем

Используем Lovable App Emails (встроенный транзакционный механизм — без Resend/SMTP):

- `setup_email_infra` + `scaffold_transactional_email`
- Шаблон `cold-outreach-syntagma.tsx` с текстом:

> Добрый день.
>
> Увидел вашу организацию среди образовательных организаций. Меня зовут Максим Шафрановский, я развиваю СИНТАГМУ — платформу для учебных центров: СДО, готовые курсы, ИИ-генерация курсов, документы и контроль прохождения обучения.
>
> Сейчас помогаем учебным центрам запускать дистанционное обучение за 7 дней: добавление учеников, назначение курсов, контроль обучения и документы в одной системе.
>
> Могу бесплатно показать за 15 минут, как это работает. Вам актуально посмотреть?

Тема и подпись редактируются в админ-настройках раздела (новая мини-форма «Шаблон письма»). При клике «Отправить письмо» вызывается `send-transactional-email`, статус лида автоматически переключается в `Письмо отправлено`, заполняется `last_email_sent_at`.

Прежде чем включить рассылку, нужно настроить домен отправителя (`Cloud → Emails`). Без верифицированного домена кнопка остаётся доступной, но при отправке покажет подсказку открыть настройки.

## 5. Про API для автоподтягивания почт и лицензий (короткий ответ)

- **DaData** (которую уже используем для ИНН): по `findById/party` возвращает ОГРН, адрес, руководителя, ОКВЭД. **Email и телефон НЕ отдаёт стабильно** — это не публичные реквизиты, в открытых данных ФНС их нет. На платных тарифах DaData есть «контакты», но это слабопокрытое поле и для учебных центров обычно пусто.
- **Лицензии (Рособрнадзор / ФРДО)**: открытого REST API c CORS нет. Есть выгрузка реестра лицензий `isga.obrnadzor.gov.ru` (XML/Excel дамп) и реестр ФРДО (поиск по сайту, без API). Реалистичный путь — раз в N дней парсить дамп edge-функцией и складывать в таблицу `licensed_orgs`, потом подтягивать к лиду по ИНН.

Поэтому **в первой итерации не делаем автоподтяжку**: добавляем поля вручную + импорт из Excel (как раз файл «Лиды Синтагма — июнь»). Если ок — следующим шагом сделаю edge-функцию-парсер реестра Рособрнадзора по ИНН для подсказок сайт/лицензия.
