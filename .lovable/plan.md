## 2. Парсер реестра Рособрнадзора по ИНН

Открытого REST API у `isga.obrnadzor.gov.ru` нет. У реестра есть публичный поиск с фильтром по ИНН — выдача HTML/JSON с лицензиями (номер, дата, статус, действует ли, адреса). Парсим серверно (Edge Function), результат кэшируем в БД.

**Edge function** `parse-rosobrnadzor` (новая):
- Вход: `{ inn: string }`.
- Делает запрос к поисковому endpoint реестра (`https://isga.obrnadzor.gov.ru/...`), при необходимости — fallback на парсинг HTML страницы выдачи (через `deno-dom`).
- Возвращает: `{ found: bool, license_number, license_date, status, registry_url, org_name, address, education_programs[] }`.
- Параллельно тянет данные из DaData (`findById/party`, ключ `DADATA_API_KEY` — спрошу при включении) для официального названия, КПП, адреса, руководителя.

**Таблица-кэш** `rosobrnadzor_licenses`:
- `inn` (PK), `license_number`, `license_date`, `license_status`, `org_name`, `address`, `registry_url`, `raw_json`, `fetched_at`.
- RLS: чтение/запись — только `admin` (через `has_role`), `service_role` — всё.
- GRANT по правилам.

**Таблица лидов** `sales_leads` (отдельно от `org_leads`, та для кабинета организации):
- `name`, `inn`, `website`, `email`, `phone`, `source`, `status`, `next_step`, `notes`, `license_cache` (jsonb), `last_email_sent_at`, `user_id`.
- RLS: только админ.
- GRANT по правилам.
