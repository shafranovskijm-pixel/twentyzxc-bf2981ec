

## Проблема

При скачивании PDF текст обрезается на границе страниц — `html2canvas` захватывает весь документ как одно изображение, и при разбиении на страницы A4 строки разрезаются пополам.

## Решение

Добавить отступы при разбиении страниц, чтобы текст не обрезался на границах. Вместо простого деления по высоте A4, каждая следующая страница будет начинаться с небольшим перекрытием (overlap), гарантируя что строки не режутся.

### Изменения в `src/components/admin/DocumentsTab.tsx`

**Функция скачивания PDF (строки ~685-694)** — улучшить логику разбиения на страницы:
- Добавить `margin` (10мм сверху/снизу) при размещении изображения на каждой странице
- Использовать `overlap` в 5мм между страницами для предотвращения обрезки текста
- Применить белый прямоугольник на границах страниц для чистого разрыва

**Функция `generatePdfBase64`** — аналогичное исправление для email-вложений.

**`src/lib/document-templates.ts`** — добавить CSS `page-break-inside: avoid` для параграфов и строк таблиц в шаблонах документов, чтобы html2canvas рендерил с учётом естественных разрывов.
