## Цель
Превратить вкладку «Продажи» в рабочий инструмент сбора и подготовки лидов под СИНТАГМУ: загрузил файл → получил чистый список учебных центров → нашёл контакты → выгрузил CSV в Coldy.

Работаем строго с публичными данными и файлами, которые ты загружаешь. Никаких обходов закрытых реестров.

## Структура `Москва.csv`
2GIS-выгрузка, разделитель `;`, первая строка `sep=;`. Колонки:
`id, name, city_name, geometry_name, office, post_code, phone, fax, email, website, vkontakte, instagram, lon, lat, category, subcategory`.

ИНН/ОГРН/лицензии в файле нет — будем фильтровать по `category/subcategory/name` (учебные центры, ДПО, автошколы и т.д.) и обогащать ИНН по названию через DaData (уже подключено), а контакты брать из колонок файла + сайта организации.

## Что делаю

### 1. Расширяю схему `sales_leads` (миграция)
Добавляю недостающие поля: `region text, city text, address text, license_number text, license_date date, category text, dedup_hash text`. Индексы по `inn`, `email`, `phone`, `dedup_hash` для быстрого дедупа.

### 2. Кнопка «Импорт XLSX/CSV»
Открывает диалог:
- выбор файла (.csv, .xlsx — парсю через `xlsx` npm пакет на клиенте, уже есть в проекте? — добавлю `xlsx`/`papaparse`);
- автодетект разделителя и кодировки (`sep=;` строка, UTF-8/Windows-1251);
- автоматический mapping колонок → поля лида (по словарю синонимов: «Наименование/Организация/name» → name, «ИНН/inn» → inn и т.д.). Если не угадал — ручной mapping в таблице.
- предпросмотр первых 20 строк с подсветкой «образовательная / не образовательная / дубль / без контактов».
- фильтры импорта (чекбоксы): только с email, только с телефоном, только образовательные, регион.
- кнопка «Импортировать N лидов».

Дедуп при импорте: по `inn` (если есть), иначе по `email`, иначе по `phone`, иначе по нормализованному `name+city`. Сначала проверка внутри файла, потом против существующих `sales_leads`.

### 3. Фильтр «образовательная организация»
Эвристика по `name + category + subcategory + website`:
- whitelist слов: учебный центр, ДПО, образоват, школа, автошкола, курсы, академия, колледж, институт, тренинг-центр, повышение квалификации, профобучение, АНО, НОЧУ, ЧОУ;
- blacklist: ремонт, кафе, ресторан, такси, доставка, авто (без «школа»), стоматолог и т.д.
- результат — поле `category = "education"` в лиде, остальные помечаются `category = "other"` и в импорт по умолчанию не идут.

### 4. Кнопка «Найти лиды» (веб-поиск)
Использую уже подключённый Firecrawl (или подключу, если ещё нет). Edge-функция `find-education-leads`:
- вход: регион, тип (ДПО / автошкола / онлайн-школа / лицензированная), год лицензии, количество (1–50);
- собирает поисковые запросы вида `"Сведения об образовательной организации" "Дата предоставления лицензии" "2026" "{регион}" "{тип}" email`;
- Firecrawl `/search` → топ N результатов → `/scrape` главной + страницы «Контакты»/«Сведения» → регэкспы достают email, телефон, название, № лицензии, дату;
- дедуп против `sales_leads` → вставка с `source = "Веб-поиск: {запрос}"`.

Это всё публичный веб-поиск, без обхода `islod.obrnadzor.gov.ru`. Старую кнопку «Из реестра Рособрнадзора» перевешиваю на этот же flow с фиксированным запросом по реестру лицензий — функция `parse-rosobrnadzor` становится тонкой обёрткой над `find-education-leads` с пресетом.

### 5. Кнопка «Обогатить контакты»
Для выделенных лидов (чекбоксы в таблице) или для всех без email:
- если есть ИНН → DaData (уже есть `dadata-lookup`);
- если ИНН нет → DaData suggest по названию + городу, берём первый матч с совпадающим городом;
- если есть сайт → Firecrawl scrape главной и `/contacts`, регэкспом достаём email/телефон, заполняем пустые поля.
Прогресс-бар, лимит 1 запрос/300мс. Старая «Синхр. все реквизиты» становится этим обогащением.

### 6. Фильтры таблицы
Над таблицей дропдаун «Фильтр» с пресетами:
- Все / Новые / Есть email / Есть телефон / Без контактов / Письмо отправлено / Ответили / Демо / Не интересно / Позже / Клиент.
Пресеты мапятся на комбинацию `status` + наличие полей. Добавляю в `STATUSES` отсутствующие значения (`later`, `client`).

### 7. Кнопка «Подготовить письмо»
Уже есть «Шаблон письма» — добавляю кнопку прямо в строке лида (иконка ✉ рядом с «отправить»): открывает диалог с подставленными `{org}/{contact}` и текстом из ТЗ (СИНТАГМА, Максим Шафрановский, демо 15 минут). Можно редактировать → «Отправить» (через существующий `send-document-email`).

### 8. Кнопка «Экспорт для рассылки» (Coldy)
Над таблицей. Экспорт текущей выборки (с учётом фильтров и чекбоксов) в CSV:
колонки `email, name, website, phone, inn, region, notes`. Только лиды с непустым email. UTF-8 с BOM, разделитель `,`.
