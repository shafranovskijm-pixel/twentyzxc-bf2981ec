

## План: Переработать тему «Бирюза» — целостная атмосфера

### Проблема
Тема «Бирюза» выглядит несобранно: фон-градиент не совпадает с баннером, хедер/сайдбар не вписываются в палитру, нет ощущения единой картины ни в светлой, ни в тёмной теме. Не хватает глубины, серебристого засвета и атмосферных деталей.

### Что делаю

#### 1. Фон — 5-ступенчатый градиент как на баннере (`admin-themes.ts`)

Текущий `bgClass` имеет 4 via-точки, но переход слишком резкий. Сделаю более плавный с промежуточным серебристо-бирюзовым:

```
bgClass: "bg-gradient-to-b from-[#c0efe8] via-[#5ab8a8] via-[#1a4a50] to-[#050e12]"
```

Проблема в том, что Tailwind `via` работает только один раз. Нужен inline `background` через CSS вместо классов, чтобы иметь настоящий multi-stop градиент:

```css
background: linear-gradient(to bottom, 
  #d4f5ef 0%,      /* серебристо-белый верх */
  #7dd4c4 15%,     /* светлая бирюза */
  #3da898 30%,     /* насыщенная бирюза */
  #1a5a58 55%,     /* глубокий тил */
  #0c2a30 80%,     /* тёмный океан */
  #050e12 100%     /* почти чёрный */
)
```

#### 2. Хедер и сайдбар — стекло, не контраст

- `headerClass`: прозрачный с сильным blur, тонкая бирюзовая граница
- `sidebarClass`: полупрозрачный тёмно-бирюзовый с backdrop-blur
- `cardClass`: полупрозрачные карточки с бирюзовой подсветкой бордеров

#### 3. Атмосферные слои — усилить (`Admin.tsx`)

Для бирюзы: увеличить opacity атмосферных фрагментов, добавить бирюзовое свечение (дополнительный CSS glow-элемент поверх), чтобы баннер «проливался» на страницу сильнее.

#### 4. Частицы — доработать (`ThemeAnimations.tsx`)

Увеличить количество частиц (25→40), добавить разнообразие: часть — крупные мерцающие «капли» (`w-2 h-2`), часть — мелкая серебристая пыль. Добавить горизонтальный дрейф для ощущения глубины.

#### 5. Бирюза в тёмном режиме

Сейчас тема не зависит от dark/light. Поскольку `forceLight` не установлен, в тёмном режиме используются те же цвета. Нужно убедиться что фон красиво работает в обоих режимах — inline background будет единым.
