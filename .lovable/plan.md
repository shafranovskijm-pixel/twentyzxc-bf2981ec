## Что меняем

Договор рендерится как один большой растр (html2canvas) и режется на страницы в `src/lib/document-pdf.ts`. Значит колонтитул и номера страниц должны рисоваться нативно в jsPDF, а не в HTML — тогда они гарантированно повторяются на каждой странице и не съезжают на разрывах.

### 1. Колонтитул на каждой странице (`src/lib/document-pdf.ts`)

- Перед `html2canvas` в iframe скрываю HTML-плашку `.brand-strip` (сейчас она есть только вверху первой страницы) и уменьшаю верхний паддинг `body`, чтобы контент не «прыгал».
- Ввожу отступы: `headerMm = 14` (тёмная плашка `#15171e` с «24ZXC» жёлтым акцентом и подписью «Web & Licensing Studio») и `footerMm = 10` (тонкая жёлтая линия + номер страницы).
- Полезная высота страницы = `pdfHeight - headerMm - footerMm`; каждый срез рисуется с `y = headerMm` (сейчас `margin=0` — контент прижимается к самому краю).
- После добавления всех страниц прохожу `pdf.setPage(i)` и на каждой рисую:
  - прямоугольник шапки + текст «24ZXC» / «WEB & LICENSING STUDIO»;
  - жёлтую линию футера + «Страница i из N» справа и «Договор №… от …» слева (данные принимаю опциональным аргументом `meta?: { title?: string }` в `generatePdfBlob`, чтобы не ломать текущих вызовов — по умолчанию рисуется только номер).

### 2. Аккуратные разрывы

- Существующий список «не резать» уже покрывает `p, li, h1-h3, tr, .signatures, .signature-block`. Расширю его: `.section, .bank-header tr, .totals-box, tfoot tr` — сейчас нижние итоги и шапка банковских реквизитов могут попадать на границу.
- Учтётся уменьшенная usable-высота из п.1, поэтому разрывы будут пересчитаны с учётом полей под колонтитулы.

### 3. Печать +15% (`src/lib/document-templates.ts`)

- `.stamp-img { height: 100px }` → `115px`.
- `body.invoice-mode .stamp-img { height: 90px }` → `104px` (та же пропорция).
- Ничего больше в шаблонах не трогаю.

### Вне рамок

- Экспорт `.docx` через edge-функцию не меняю.
- Дизайн шаблонов и содержимое договора остаются без изменений — только колонтитул PDF и размер печати.
