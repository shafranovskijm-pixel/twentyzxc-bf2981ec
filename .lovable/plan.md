

## Улучшение отображения админ-панели (Планер + Продажи)

На скриншоте видно несколько проблем: тесное расположение элементов, обрезанный текст в карточках задач, слабая визуальная иерархия. Вот план улучшений:

### 1. Планер — недельный календарь

| Проблема | Решение |
|---|---|
| Текст задач обрезается ("Договор д...", "Звонок по синтагме в...") | Увеличить минимальную ширину колонки, показывать полный текст при наведении (tooltip) |
| Карточки задач тесные | Добавить padding, увеличить межстрочный интервал |
| Нет цветовой кодировки по типу | Добавить цветную полоску слева по статусу (жёлтый — в работе, зелёный — готово, серый — сделать) |
| Сегодняшний день слабо выделен | Усилить подсветку текущего дня — более яркая рамка и фоновый градиент |

### 2. Прогноз поступлений

| Проблема | Решение |
|---|---|
| Карточки мелкие, числа сливаются | Увеличить размер шрифта сумм, добавить разделительные линии |
| Нет динамики / сравнения | Добавить стрелку тренда ↑↓ относительно прошлого периода |

### 3. AI-ассистент продаж

| Проблема | Решение |
|---|---|
| Занимает 2/3 экрана пустым пространством | Уменьшить высоту чата до ~400px, сделать auto-grow при появлении сообщений |
| Быстрые вопросы мелкие | Увеличить кнопки, добавить иконки к каждому вопросу |

### 4. Общий лейаут

| Проблема | Решение |
|---|---|
| Планер и продажи идут вертикально — много скролла | Сделать планер фиксированной высоты со скроллом внутри колонок, продажи видны без скролла |
| Нет визуального разделения секций | Добавить заголовки-разделители между планером и блоком продаж |

### Файлы для изменения

| Файл | Что меняется |
|---|---|
| `src/components/admin/PlannerTab.tsx` | Tooltip на задачах, цветная полоска статуса, усиленная подсветка "сегодня", max-height с overflow на колонках |
| `src/components/admin/SalesAssistant.tsx` | Уменьшить высоту чата, увеличить кнопки быстрых вопросов, добавить иконки, тренд-стрелки в ForecastCards |
