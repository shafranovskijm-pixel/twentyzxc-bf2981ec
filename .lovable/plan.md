

## План: Реквизиты организации в карточке договора

### Что добавить
В диалог «Редактировать договор» (и «Новый договор») добавить блок «Реквизиты организации» с информацией: **ИНН, КПП, ОГРН, юр. адрес, руководитель (должность + ФИО)**. Каждое поле — кнопка-чип с копированием в буфер по клику (стандарт, как в `NmoCopyField`).

### Источник данных
1. **Если клиент уже есть в CRM** (`clients` таблица) — подтягиваем по совпадению `name` ↔ `client_name` (case-insensitive). Если совпадений несколько — берём по `inn`.
2. **Если клиента нет, но есть ИНН** (после поиска через DaData) — делаем повторный `dadata-lookup`, чтобы показать `kpp`, `ogrn`, `address`, `management_name/post`.
3. **Кнопка «Сохранить как клиента»** в блоке — если организации нет в CRM, одним кликом создаём запись в `clients` с найденными реквизитами (чтобы в следующий раз они подтянулись из БД, а не через API).

### UI

```text
┌─ Реквизиты организации ──────────────── [↻ Обновить из DaData] ─┐
│ [📋 ИНН: 1657267820]  [📋 КПП: 165701001]                       │
│ [📋 ОГРН: 1167...]                                              │
│ [📋 Юр. адрес: 420095, Республика Татарстан, г. Казань...]      │
│ [📋 Руководитель: Генеральный директор Иванов И.И.]             │
│                                                                  │
│ ⓘ Клиент не найден в CRM  [+ Сохранить в клиенты]               │
└──────────────────────────────────────────────────────────────────┘
```

Блок сворачиваемый (`Collapsible`), по умолчанию **раскрыт при редактировании** (когда виден `client_name`) и **свёрнут при создании нового**.

### Логика подгрузки
- В `startEdit(c)` после установки `clientName` запускаем `useEffect` (или прямой вызов): SELECT из `clients` WHERE `lower(name) = lower(client_name)` LIMIT 1.
- Найденные реквизиты сохраняются в локальный state `orgRequisites`.
- При нажатии «↻ Обновить из DaData» (если есть ИНН) — заново через edge `dadata-lookup` и предложение обновить запись в `clients`.
- При нажатии «+ Сохранить в клиенты» — INSERT в `clients` с текущими полями.
