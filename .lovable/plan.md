

# Улучшение визуала конструктора сайтов

## Текущее состояние

Конструктор уже имеет хорошую функциональность: 21 тип блоков, горизонтальную группировку, полноширинные hero-картинки, 15 шаблонов с уникальными палитрами, анимации и hover-эффекты. Но есть несколько областей, где можно значительно улучшить опыт сборки красивого сайта.

---

## Предлагаемые улучшения

### 1. Готовые секции (Section Templates)

Сейчас пользователь добавляет блоки по одному и должен сам настраивать стили. Нужны **готовые стилизованные секции** -- не целые шаблоны страниц, а отдельные секции, которые можно вставить в любой проект.

Примеры секций:
- **Hero с CTA** -- заголовок + описание + кнопка, уже стилизованные
- **Блок преимуществ** -- 3 icon-text в ряд с карточечным фоном
- **Отзывы** -- карточки с цитатами в красивом оформлении
- **Команда** -- колонки с фото и описанием
- **CTA-баннер** -- яркий блок с градиентным фоном и кнопкой
- **FAQ** -- стилизованный аккордеон
- **Ценовые планы** -- табы с тарифами

Разница от текущих "Примеров блоков" -- секции включают несколько связанных блоков с полной стилизацией, а не один голый блок.

### 2. Цветовые схемы (Color Schemes)

Добавить выбор цветовой схемы, которая автоматически применяется ко ВСЕМ блокам на странице. Пользователь выбирает тему -- и все заголовки, тексты, карточки, кнопки перекрашиваются.

Схемы:
- Midnight Blue (тёмно-синий + голубые акценты)
- Forest (тёмно-зелёный + изумрудные акценты)
- Sunset (тёмно-бордовый + оранжевые акценты)
- Royal Purple (тёмно-фиолетовый + лавандовые акценты)
- Warm Gold (чёрный + золотые акценты)
- Arctic (холодный серый + белые акценты)

### 3. Улучшение рендера навигации (Navbar)

Сейчас navbar выглядит как простой текст с иконкой "бургер". Нужно сделать его реалистичнее:
- Логотип слева (название проекта или кастомный текст)
- Пункты меню справа с hover-подсветкой
- Полупрозрачный фон с backdrop-blur
- Мобильная адаптация -- на узких экранах скрывать в бургер

### 4. Улучшение рендера кнопок

Кнопки выглядят базово. Улучшения:
- Стиль `gradient` -- добавить shimmer-анимацию при наведении
- Новый стиль `glass` -- стеклянная кнопка с backdrop-blur
- Новый стиль `neon` -- неоновое свечение вокруг кнопки
- Иконки для кнопок (стрелка, телеграм и т.д.)

### 5. Улучшение columns-блока

Сейчас колонки выглядят простенько (border + текст). Добавить:
- Иконки/эмодзи вверху каждой колонки (формат: `🎨|Заголовок|Описание`)
- Поддержку изображений в колонках
- Hover-эффект на каждую колонку отдельно
- Фон карточек из стилей блока

### Цветовые схемы -- логика применения

При выборе схемы проходим по всем блокам и обновляем:
- `heading` -- textColor и gradientText
- `text` -- textColor  
- `card` -- backgroundColor и borderColor
- `button` -- accentColor
- `navbar`, `footer` -- backgroundColor
- `counter`, `icon-text` -- textColor

Это одноразовое действие (не глобальная настройка), чтобы пользователь мог потом донастроить отдельные блоки.

### Секции -- примеры содержимого

Каждая секция это массив из Omit<PlaygroundBlock, 'id'>[] с полной стилизацией. Пользователь кликает -- все блоки секции добавляются в конец канваса.

### Navbar -- улучшенный рендер

Первый элемент контента (до первого `\n`) становится "логотипом" (жирный текст слева). Остальные пункты -- справа. Добавляется `backdrop-blur-md` и `bg-black/50` для стеклянного эффекта.
