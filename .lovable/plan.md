## Проблемы в текущем PDF

1. «Страница X из N» и «Договор №…» рисуются `pdf.text(..., "helvetica")` — в jsPDF стандартный Helvetica не поддерживает кириллицу, поэтому в футере вылезают иероглифы (`!B@0=8F0 5 87`).
2. Слайсы контента сохраняются как `image/jpeg` с качеством `0.72` → цвета блёклые, фон сероватый, тонкие линии и печать замыленные — выглядит как «копия».
3. Печать нужно увеличить ещё на 20% (сейчас после прошлой правки 115px / 104px).

## Что делаю

### 1. Кириллица в колонтитуле (`src/lib/document-pdf.ts`)
- Подключаю встроенный в jsPDF шрифт с юникодом: динамически импортирую `jspdf/dist/polyfills.es.js` не нужно — беру готовый Roboto из `jspdf` через `addFont` с base64 (лежит в `src/assets/fonts/Roboto-Regular.ttf.base64` — добавлю мини-ассет) **или**, проще и без нового ассета, использую пакет `@fontsource/roboto` уже установленный в проекте? Проверю. Если нет — беру `PT Sans` через `fetch` из `/fonts` не подходит для edge-совместимости.
- Финальный вариант: добавляю файл `src/lib/pdf-fonts.ts`, который лениво фетчит TTF из Google Fonts (Roboto Regular + Bold) один раз, конвертит в base64 и регистрирует в jsPDF (`doc.addFileToVFS` + `doc.addFont`). Дальше `pdf.setFont("Roboto", "normal")` и весь колонтитул печатается кириллицей корректно.
- Fallback: если fetch не удался — оставляю латинскую строку `Page i / N` без падения.

### 2. Качество и «сочность» цвета
- Заменяю `sliceCanvas.toDataURL("image/jpeg", 0.72)` → `toDataURL("image/png")` + `pdf.addImage(..., "PNG", ..., "SLOW")`. PNG без потерь, цвета фирменного `#15171e` / `#d4be37` в шапке шаблона перестанут «выцветать».
- Поднимаю `renderScale` для средних документов: было `1 / 1.15 / 1.35`, ставлю `1.35 / 1.6 / 2` (кроме гигантских, чтобы не раздувать RAM). При PNG размер файла вырастет — компенсирую тем, что для не-цветных страниц (крайне редкий кейс) не трогаю; при желании оставлю `JPEG 0.95` как запасной путь если итог >8 МБ.
- Отключаю `imageTimeout: 5000` → `15000`, чтобы печать/подписи (крупные PNG) успевали загружаться в html2canvas и не подменялись пустотой.

### 3. Печать +20% (`src/lib/document-templates.ts`)
- `.stamp-img { height: 115px }` → `138px`.
- `body.invoice-mode .stamp-img { height: 104px }` → `125px`.
- Больше в шаблонах ничего не трогаю.

### 4. Мелкая полировка колонтитула
- Верхняя плашка: делаю её чуть тоньше (`headerMm 14 → 12`), потому что PNG-контент теперь ярче и «толстая» шапка визуально давит.
- Футер: тонкая золотая линия остаётся, номер страницы форматирую как `— 3 / 12 —` по центру, слева — название документа (уже приходит через `meta.title`).

## Вне рамок
- Не переписываю всю систему на серверный рендер (Puppeteer / Gotenberg) — это большой отдельный проект; текущий стек (html2canvas + jsPDF) остаётся, улучшаем качество и типографику.
- Шаблоны договоров (`document-templates.ts`) кроме размера печати не трогаю.
- Подписание PDF (`pdf-signer.ts`), .docx экспорт и рассылка не меняются.

## Проверка
1. Сгенерирую договор из админки, скачаю PDF.
2. Открою в вьюере: колонтитул на каждой странице содержит «Страница 2 из 5» кириллицей, никаких `!B@0=8F0`.
3. Цвета шапки шаблона совпадают с превью в браузере (тёмный фон, золотой акцент), тонкие линии таблицы чёткие.
4. Печать заметно крупнее (сравню с предыдущей версией из истории).
