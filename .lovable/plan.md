
# Улучшенный план: Игровая механика с качеством видеоигр

## Выбор технологии

После анализа рекомендую **гибридный подход**:

1. **React Three Fiber** — для 3D сундука (уже установлен в проекте)
2. **Framer Motion** — для перетаскивания ключей (нужно установить)
3. **Lottie** — для эффектов частиц и свечения

Это даст качество, сравнимое с современными видеоиграми:
- Реалистичный 3D сундук с освещением
- Физика перетаскивания ключей
- Профессиональные эффекты частиц

## Детализация компонентов

### 1. 3D Сундук (React Three Fiber)

**Источник модели:** Sketchfab — бесплатная glTF модель с анимацией
- "Treasure Chest Animation" by Matt Harris (CC Attribution)
- Включает: открытие, тряска, закрытие
- Формат: .glb (бинарный glTF)

**Компонент:**

```text
src/components/game/
├── TreasureChest3D.tsx     # Canvas + 3D сцена
├── ChestModel.tsx          # glTF модель + анимации  
├── ChestLighting.tsx       # Освещение + тени
└── ChestParticles.tsx      # Частицы при открытии
```

**Функции:**
- Idle-анимация: сундук слегка "дышит" (scale pulse)
- Hover-анимация: подсветка, приглашение к действию
- Открытие: крышка поднимается с инерцией
- Частицы: золотые искры вылетают изнутри

### 2. Инвентарь с Drag-and-Drop (Framer Motion)

**Установка:** `framer-motion` (дополнительная зависимость)

**Компонент:**

```text
src/components/game/
├── InventoryBar.tsx        # Панель инвентаря
├── DraggableKey.tsx        # Перетаскиваемый ключ
└── DropZone.tsx            # Зона сброса (замок сундука)
```

**Функции:**
- Ключи перетаскиваются мышью/пальцем
- Spring-физика: ключ "пружинит" при отпускании
- Визуальная обратная связь: подсветка при наведении на замок
- Звуковые эффекты (опционально): клик замка

### 3. Эффекты частиц (Lottie)

**Источник:** LottieFiles — готовые анимации
- "Treasure Chest Burst" — золотые частицы
- "Sparkle Effect" — мерцание

**Интеграция:**
- Библиотека: `lottie-react` или `@lottiefiles/react-lottie-player`
- Запуск: при открытии сундука
- Позиция: поверх 3D сцены

## Пользовательский опыт

### Сценарий взаимодействия

1. **Посетитель видит карточку услуги**
   - Кнопка "Взять ключ" с анимацией свечения
   - При наведении — ключ "подпрыгивает"

2. **Клик на "Взять ключ"**
   - Ключ 3D-анимированно летит к инвентарю
   - Инвентарь появляется внизу экрана
   - Звук "дзинь" (опционально)

3. **Инвентарь с ключами**
   - Fixed панель с drag-and-drop
   - При наведении — tooltip с названием услуги
   - Подсветка при перетаскивании

4. **Скролл к сундуку**
   - 3D сундук с idle-анимацией
   - Замок светится, приглашая

5. **Перетаскивание ключа к сундуку**
   - Ключ следует за курсором
   - При приближении к замку — магнит-эффект
   - Drop zone подсвечивается

6. **Открытие сундука**
   - Ключ входит в замок (0.5s)
   - Поворот ключа (0.3s)
   - Замок исчезает
   - Крышка поднимается с инерцией (0.8s)
   - Золотые частицы вылетают
   - Форма появляется с glow-эффектом

## Альтернативный упрощённый вариант

Если 3D кажется избыточным, можно использовать только **Lottie + Framer Motion**:

- **Lottie-анимация сундука** вместо 3D модели
- **Framer Motion drag** для ключей
- Качество 7/10, но проще в реализации

## Рекомендация

Учитывая, что `@react-three/fiber` и `@react-three/drei` **уже установлены** в проекте, рекомендую полный 3D-вариант. Это даст:

- Уникальный игровой опыт
- Качество уровня видеоигр
- Запоминаемость бренда
- Вирусный потенциал

Единственное ограничение — нужна подходящая glTF модель сундука (можно взять бесплатную с Sketchfab или создать стилизованную в Blender).
