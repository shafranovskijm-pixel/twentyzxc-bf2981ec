

## План: Кнопка «Войти как организация» в админке

В таблице организаций (OrganizationsTab) добавить кнопку-глазик рядом с кнопкой удаления. По клику — переход на `/org` с автоматической авторизацией под учёткой организации.

### Реализация

**Файл: `src/components/admin/OrganizationsTab.tsx`**
- Добавить кнопку `<Eye>` в колонку «Действия» рядом с корзиной
- По клику — открывать `/org` в новой вкладке (window.open)

**Файл: `src/pages/OrgPanel.tsx`**
- Добавить проверку: если текущий пользователь — админ (`has_role` admin), пропускать проверку `isOrg` и показывать панель организации
- Админ видит выбор организации или сразу попадает в первую доступную

**Файл: `src/hooks/use-org-auth.tsx`**
- Расширить хук: если пользователь — admin, тоже считать `isOrg = true`
- Добавить возможность передать `organizationId` через URL-параметр (`/org?id=xxx`)

### Логика
1. Админ нажимает 👁 → открывается `/org?id={org.id}`
2. `useOrgAuth` проверяет роль — если admin, пропускает проверку organization
3. `OrgPanel` берёт `id` из URL и загружает данные этой организации вместо поиска по `user_id`

### Файлы

| Файл | Изменение |
|------|-----------|
| `src/components/admin/OrganizationsTab.tsx` | Кнопка Eye в Actions |
| `src/hooks/use-org-auth.tsx` | Админ = доступ к орг-панели |
| `src/pages/OrgPanel.tsx` | Поддержка `?id=` для просмотра конкретной организации |
