

## Plan: Светлый фон для тем «Свежесть» и «Офис»

### Проблема
Все 5 тем сейчас подчиняются глобальному переключателю dark/light. По умолчанию включён dark-режим, поэтому все темы выглядят тёмными — даже «Свежесть» и «Офис», которые по задумке должны быть светлыми.

### Решение
Добавить в `AdminTheme` поле `forceLight?: boolean`. Темы «Свежесть» и «Офис» будут принудительно использовать светлый фон, убирая класс `dark` с `<html>` при их активации. При переключении на другую тему — восстанавливается выбранный пользователем режим.

### Изменения

**`src/data/admin-themes.ts`**
- Добавить поле `forceLight?: boolean` в интерфейс `AdminTheme`
- Установить `forceLight: true` для тем `freshness` и `office`

**`src/pages/Admin.tsx`**
- В `useEffect` по `activeThemeId` + `isDark`: если тема имеет `forceLight: true`, убирать класс `dark` с `documentElement` (принудительно светлый). Иначе — использовать `isDark` как обычно.
- Скрыть переключатель light/dark когда тема `forceLight`

### Файлы
- `src/data/admin-themes.ts` — добавить `forceLight`
- `src/pages/Admin.tsx` — логика принудительного light-режима
