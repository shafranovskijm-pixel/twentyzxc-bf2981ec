## План: Кнопка «Загрузить 10 свежих лицензий»

В шапке таблицы Продажи добавляю кнопку **«⬇ 10 свежих лицензий»** рядом с «Импорт из договоров».

### Что делает кнопка
1. Вызывает Edge Function `parse-rosobrnadzor` в режиме `recent` с параметрами `{ region: "77", limit: 10 }` (Москва по умолчанию; рядом селект региона — 77/78/далее).
2. Функция парсит реестр `islod.obrnadzor.gov.ru/rlic`, забирает первые 10 строк отсортированных по дате выдачи, для каждой строки заходит на `/view/{id}` и достаёт: название, ИНН, ОГРН, адрес, № лицензии, дата, статус, телефон/email (если есть).
3. Возвращает массив объектов; на клиенте идёт `upsert` в `sales_leads` по ИНН (если такой ИНН уже есть — пропускаем), source = `rosobrnadzor`, `license_cache` заполняется, статус = `new`.
4. Toast «Добавлено N новых лидов из реестра» и перезагрузка списка.

### Технические детали
- `supabase/functions/parse-rosobrnadzor/index.ts` — добавляю/чиню ветку `mode: "recent"` с возвратом массива, а не только обогащением. Уже есть наработка с прошлого шага — дорабатываю парсинг детальной страницы.
- `src/components/admin/SalesTab.tsx` — кнопка + селект региона + state `loadingRecent`, обработчик и upsert (skip по ИНН через локальную проверку существующих лидов).
- Если функция не вернула данные (реестр недоступен/изменилась разметка) — показываю toast с ошибкой и текстом ответа для дебага.

### Открытый вопрос
Сейчас по умолчанию регион **77 (Москва)** и тип реестра — **лицензии на образовательную деятельность**. Подтверди, что начинаем с этого, или нужен другой регион/сразу несколько.
