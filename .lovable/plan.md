
# Улучшение навигации, шаблонов и публикации в конструкторе

## Что будет сделано

### 1. Навигация (navbar) с привязкой к блокам
Сейчас пункты меню навигации -- просто текст без функциональности. Улучшим их так, чтобы каждый пункт мог ссылаться на конкретный блок на странице (якорная навигация) или на внешнюю ссылку.

- Каждому блоку добавляется необязательное поле `anchorId` (идентификатор-якорь)
- В редакторе блока появляется поле "ID якоря" (например, "about", "services")
- Формат контента navbar меняется: `Главная|#hero\nО нас|#about\nУслуги|https://example.com`
- На опубликованной странице и в превью пункты меню работают как ссылки: `#якорь` прокручивает к блоку, `https://...` открывает внешнюю страницу
- В редакторе navbar добавляется подсказка с описанием формата

### 2. Улучшение шаблонов
- Шаблоны "Визитка", "Лендинг", "Портфолио", "Стартап" дополняются блоками navbar и footer
- Пункты navbar в шаблонах сразу привязаны к якорям блоков внутри шаблона
- Шаблоны становятся полноценными страницами "из коробки"

### 3. Ввод slug перед сохранением
Сейчас slug генерируется случайно. Вместо этого:
- При нажатии "Сохранить" открывается диалоговое окно с полем для ввода желаемого slug (латиница, цифры, дефис)
- Показывается итоговый URL: `24zxc.ru/p/my-project`
- Если пользователь оставляет поле пустым -- генерируется случайный slug
- Валидация: только `a-z`, `0-9`, `-`, минимум 3 символа
- Поле slug можно ввести только при первом сохранении; при повторном сохранении используется тот же slug
