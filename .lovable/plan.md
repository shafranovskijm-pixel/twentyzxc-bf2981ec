

# Улучшения конструктора сайтов

## Текущее состояние
Конструктор уже имеет: 13 типов блоков, drag-and-drop сортировку, undo/redo, 8 шаблонов страниц, 7 примеров блоков, 18 анимаций, 5 hover-эффектов, превью по устройствам, сохранение в базу и публикацию по ссылке.

## Предлагаемые улучшения

### 1. Новые типы блоков
- **Колонки (2-3 колонки)** -- сейчас все блоки идут строго вертикально, нет возможности расположить контент рядом (например, 3 карточки в ряд)
- **Иконка + текст** -- блок с иконкой (emoji) и текстом рядом, популярный для "преимуществ"
- **Форма обратной связи** -- простая форма (имя + email + сообщение) с отправкой в Telegram или сохранением в базу
- **Таймер обратного отсчёта** -- для промо-страниц и событий
- **Галерея изображений** -- несколько картинок в сетке вместо одной
- **Социальные сети** -- блок с иконками соцсетей и ссылками

### 2. Улучшения редактора блоков
- **Выбор стиля кнопки** -- сейчас кнопка имеет один стиль, добавить варианты: заполненная, контурная, градиентная, с иконкой
- **Высота/ширина изображений** -- возможность задавать размеры и object-fit
- **Градиентный текст** -- опция для заголовков с градиентным цветом текста (как в основном сайте)
- **Тень блока** -- настройка box-shadow для блоков

### 3. Опубликованная страница (PlaygroundView)
Сейчас PlaygroundView не рендерит новые типы блоков (list, quote, counter, video, navbar, footer) -- они возвращают null. Это критический баг, который нужно исправить.

### 4. Улучшение UX
- **Быстрый дубликат по клику** -- показывать кнопки "Дублировать" и "Удалить" при наведении на блок прямо на канвасе
- **Drag-and-drop блоков из палитры** -- перетаскивание новых блоков из палитры на канвас (сейчас только по клику)
- **Горячие клавиши** -- Delete для удаления выбранного блока, Ctrl+D для дубликата
- **Уведомление о несохранённых изменениях** -- предупреждение при попытке покинуть страницу

### 5. Экспорт
- **Экспорт в HTML** -- скачать созданную страницу как standalone HTML файл
- **Скриншот/превью** -- автоматическая генерация превью для галереи

## Техническая часть

### Критический баг: PlaygroundView не рендерит 6 типов блоков
В `src/pages/PlaygroundView.tsx` в switch-case обрабатываются только: heading, text, button, image, divider, card, spacer. Отсутствуют: **list, quote, counter, video, navbar, footer**. Все они попадают в `default: return null`.

### Приоритет реализации
1. **Исправить PlaygroundView** (критический баг -- сохранённые проекты отображаются неполно)
2. **Колонки** (самый запрашиваемый тип блока для конструкторов)
3. **Быстрые действия на канвасе** (UX)
4. **Горячие клавиши** (Delete, Ctrl+D)
5. **Стили кнопок и градиентный текст** (визуальное разнообразие)
6. **Остальные блоки** (таймер, галерея, форма)

### Изменения в файлах
- `src/pages/PlaygroundView.tsx` -- добавить рендер недостающих блоков
- `src/data/playground-effects.ts` -- добавить новые типы блоков (columns, icon-text, countdown, gallery, socials)
- `src/components/playground/Canvas.tsx` -- рендер новых блоков, оверлей действий при наведении
- `src/components/playground/BlockEditor.tsx` -- настройки стиля кнопки, градиентный текст, тень
- `src/components/playground/BlockPalette.tsx` -- иконки для новых блоков
- `src/hooks/use-playground.tsx` -- горячие клавиши Delete/Ctrl+D, предупреждение при уходе
- `src/components/playground/ProjectTemplates.tsx` -- обновить шаблоны для использования колонок
