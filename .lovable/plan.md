

# План: Сервис регистрации на портале НМО

## Что будет сделано

### 1. Публичная страница услуги `/services/nmo`
Отдельная страница по аналогии с существующими сервисными страницами (Frdo, Landing и т.д.):
- Hero-секция с описанием услуги и ценой **35 000 ₽**
- Пошаговый процесс регистрации на портале НМО (на основе изученных документов):
  1. Подготовка документов (лицензия, приложение о ДПО)
  2. Регистрация ответственного сотрудника на Портале НМФО
  3. Подача заявки на открытие личного кабинета (org.edu.rosminzdrav.ru)
  4. Заполнение данных организации (ИНН, КПП, адреса, лицензия)
  5. Добавление ответственного лица
  6. Отправка оригиналов документов в РНИМУ им. Пирогова
  7. Подготовка паспортов ДПП для включения программ в список Портала
- Блок «Что входит в услугу» (подготовка всех документов, подача заявки, сопровождение до получения ЛК, помощь с паспортами программ)
- Форма заявки с отправкой в Telegram (как на других сервисных страницах)
- FAQ по частым вопросам (из материалов портала)

### 2. Вкладка «НМО Портал» в админке
Новая вкладка в сайдбаре админ-панели для управления заявками на регистрацию:
- Список клиентов-заявок со статусами (чеклист по этапам):
  - Документы собраны
  - Сотрудник зарегистрирован на Портале
  - Заявка подана на org.edu.rosminzdrav.ru
  - Оригиналы отправлены почтой
  - ЛК организации открыт
  - Паспорта ДПП заполнены
- Привязка к существующим клиентам из CRM
- Хранение данных для заявки: ИНН, КПП, номер лицензии, дата лицензии, данные ответственного лица (ФИО, email, телефон, СНИЛС, должность)
- Кнопка «Справочные материалы» со ссылками на загруженные PDF-документы (инструкция, порядок включения ДПП, рекомендации)

### 3. Интеграция на главную страницу
- Добавить карточку услуги НМО в существующие секции (WebDevSection или PromotionSection) со ссылкой на `/services/nmo`

### 4. База данных
Новая таблица `nmo_registrations`:
- `id`, `client_id` (nullable, ссылка на clients), `created_at`, `updated_at`
- `organization_name`, `inn`, `kpp`, `license_number`, `license_date`
- `responsible_name`, `responsible_email`, `responsible_phone`, `responsible_snils`, `responsible_position`
- `status` (text, default 'new')
- `checklist` (jsonb — хранение прогресса по этапам)
- `notes` (text)
- RLS: только admin

### 5. Загруженные PDF
Три PDF-файла будут скопированы в `public/docs/nmo/` и доступны для скачивания из админки и публичной страницы:
- `instruction07.05.2024.pdf` — Инструкция по работе в ЛК подсистемы заявок
- `PORYADOK_vklyuchenia_DPP_na_Portal.pdf` — Порядок включения ДПП
- `RECOMENDACII_po_svedeniyam_DPP.pdf` — Рекомендации по сведениям ДПП
