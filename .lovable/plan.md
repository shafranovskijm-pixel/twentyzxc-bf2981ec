

## План: Счёт на основании договора — автозаполнение данных

### Проблема
При переходе к созданию счёта из планера (или из истории документов) заполняются только `clientName` и `linkedContractId`. Реквизиты клиента (ИНН, КПП, адрес и т.д.) и услуги/сумма не подтягиваются из договора.

### Решение

#### 1. Расширить запрос contracts — добавить `amount`, `contract_type`
В `doc-contracts` query добавить поля `amount` и `contract_type`, чтобы при выборе договора знать сумму и тип.

#### 2. Расширить useEffect prefill — подтягивать реквизиты клиента из таблицы clients
При срабатывании prefill (`initialContractId`):
- По `contract.client_name` найти клиента в массиве `clients` (уже загружен в `doc-clients` query)
- Заполнить все реквизиты: `clientInn`, `clientKpp`, `clientOgrn`, `clientAddress`, `clientDirectorName`, `clientDirectorPost`
- Если у договора есть `amount` — создать одну услугу с этой суммой (например, «Услуги по договору №...»)

#### 3. Также заполнять при ручном выборе договора из селекта
Добавить аналогичную логику при изменении `linkedContractId` через Select — когда пользователь вручную выбирает договор для счёта/акта, автоматически подтягивать клиента и его реквизиты.

#### 4. Поиск предыдущего документа-договора
Дополнительно: если для этого `contract_id` уже есть сгенерированный документ типа `contract` в `generated_documents`, подтянуть из него `services` (JSON) — так счёт будет содержать те же услуги, что были в договоре.
