# Выбор ТЗ при сборке пакета «Договор + ТЗ + Счёт + Акт»

## Логика выбора ТЗ

Когда во вкладке «Документы» нажимаешь кнопку «Договор + ТЗ + Счёт + Акт»:

1. **Если у договора уже есть привязанное ТЗ** (через «Соединить с договором» во вкладке ТЗ) — берём его молча, сразу собираем пакет.
2. **Если привязки нет, но у клиента (по ИНН) одно ТЗ** — берём его молча.
3. **Если привязки нет и у клиента несколько ТЗ** — открывается компактный диалог со списком всех ТЗ клиента (номер, дата, название). Пользователь выбирает нужное → собираем пакет.
4. **Если у клиента вообще нет ТЗ** — показываем toast «У клиента нет ТЗ. Сначала создайте его во вкладке ТЗ» и не собираем пакет.

В диалоге выбора есть чекбокс «Привязать это ТЗ к договору» (по умолчанию включён) — чтобы в следующий раз не спрашивать.

## Что меняется в коде

- `DocumentsTab.tsx`:
  - В `downloadFullPackage` после поиска ТЗ — если найдено >1 кандидата и нет привязки по `contract_id`, ставим `setTzPickerOpen(true)` со списком кандидатов вместо немедленной сборки.
  - Новый локальный `Dialog` «Выберите ТЗ для пакета» со `Select` из найденных ТЗ + чекбокс привязки.
  - При подтверждении: (опц.) `update tz_documents set contract_id = ...`, затем продолжаем сборку с выбранным ТЗ.
