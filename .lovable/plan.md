

# Превращение шаблонов в реалистичные сайты

## Проблема

Все 15 шаблонов используют одинаковый базовый стиль: прозрачный фон, `#1a1a1a` карточки, `#888888` текст, `#d4a855` акценты. Результат выглядит как набросок, а не как готовый сайт.

## Решение

Переписать все шаблоны в `ProjectTemplates.tsx` с уникальной визуальной идентичностью для каждого. Каждый шаблон получит:

- Собственную цветовую палитру (фон страницы, карточки, акценты, текст)
- Реалистичные изображения с Unsplash, подходящие по тематике
- Полноценную структуру настоящего сайта (hero-секция с большим изображением, секции с колонками, footer с соцсетями)
- Визуальные акценты: градиенты на заголовках, тени на карточках, разнообразные hover-эффекты
- Больше блоков для полноты ощущения (галереи, формы, соцсети, icon-text)

## Технические изменения

### Файл: `src/components/playground/ProjectTemplates.tsx`

Полная переработка содержимого массива `PAGE_TEMPLATES`:

- Каждый шаблон получает свой объект `settings` (передаётся как `backgroundColor` в рамках блоков)
- Карточки получают уникальные `backgroundColor`, `boxShadow`, `borderRadius`
- Заголовки получают `gradientText` с уникальными градиентами
- Добавляются новые блоки: `gallery`, `socials`, `form`, `icon-text`, `columns`, `accordion`, `tabs`
- Unsplash-изображения подбираются тематически (параметры `w`, `h`, `fit=crop` для оптимизации)
- Hover-эффекты варьируются между шаблонами (`hover-lift`, `hover-glow`, `hover-scale`, `hover-brightness`)
- Анимации разнообразнее (`blur-in`, `scale-bounce`, `fade-in-left`, `flip-x`)

### Объём изменений

Только один файл: `src/components/playground/ProjectTemplates.tsx` -- полная переработка массива `PAGE_TEMPLATES` (15 шаблонов, ~600-800 строк).

Остальные файлы не затрагиваются -- вся визуализация работает через существующую систему рендеринга блоков в `Canvas.tsx` и `PlaygroundView.tsx`.
