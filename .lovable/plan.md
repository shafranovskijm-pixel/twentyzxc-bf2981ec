

## Plan: Улучшить форму добавления задачи в планере

### Проблема
Форма добавления задачи встроена прямо в узкую колонку дня (min-width 160px). Селекты клиентов и договоров слишком мелкие, выпадающий список неудобен для длинных названий организаций.

### Решение
Заменить встроенную форму на **Popover** — при нажатии «+ Задача» открывается всплывающее окно нормального размера (w-80, ~320px) с:
- Увеличенными полями ввода (h-9 вместо h-7, text-sm вместо text-xs)
- Поиском по клиентам через `Popover` + `Command` (combobox с фильтрацией) вместо обычного Select — удобно при большом списке
- Нормальным размером текста в выпадающих списках
- Кнопками «Добавить» и «Отмена» стандартного размера

### Изменения в `PlannerTab.tsx`

1. **Импортировать** `Popover, PopoverTrigger, PopoverContent` и `Command` (cmdk)
2. **Заменить inline-форму** в `DayColumn` на `Popover`:
   - Trigger — кнопка «+ Задача»
   - Content — форма шириной 320px с нормальными размерами элементов
3. **Клиент-селектор** — заменить на Command/Combobox с текстовым поиском (фильтрация по вводу), чтобы быстро находить клиента в длинном списке
4. **Договор-селектор** — оставить Select, но увеличить размер (h-9, text-sm)
5. **Input задачи** — h-9, text-sm
