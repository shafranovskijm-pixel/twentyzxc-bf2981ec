
# Примеры блоков -- по 3 варианта в каждой категории

## Что изменится

Сейчас в каждой категории аккордеона "Примеры блоков" по 1 примеру на тип. Добавим по 3 варианта для каждого типа блока, чтобы пользователь мог выбирать из разных стилей.

```text
v Примеры блоков
  > Структура сайта (9 примеров)
      Меню навигации (3 варианта: стандартное, минималистичное, с логотипом)
      Футер (3 варианта: стандартный, расширенный, минимал)
      Колонки "3 шага" (3 варианта: процесс, иконки, карточки)
  > Контент (12 примеров)
      Герой-заголовок (3 варианта: классический, жирный, градиент)
      Преимущества (3 варианта: с эмодзи, с иконками, нумерованный)
      FAQ карточка (3 варианта: стоимость, сроки, гарантии)
      YouTube видео (3 варианта: стандарт, с заголовком, мини)
  > Статистика и акции (9 примеров)
      Статистика (3 варианта: 3 счётчика, 4 счётчика, с заголовком)
      Таймер акции (3 варианта: классический, агрессивный, мягкий)

  > Визуал и галереи (9 примеров)
      Галерея 2 фото (3 варианта: пейзажи, бизнес, архитектура)
      Галерея 6 фото (3 варианта: природа, продукты, минимал)
      CTA секция (3 варианта: стандарт, с иконкой, двойная кнопка)
  > Бизнес (12 примеров)
      Ценовая карточка (3 варианта: премиум, базовый, про)
      Команда (3 варианта: 3 человека, 2 человека, с описанием)
      Форма заявки (3 варианта: полная, минимал, обратный звонок)
```

## Технические детали

### Файл: `src/components/playground/ProjectTemplates.tsx`

1. Массив `BLOCK_EXAMPLES` -- добавить по 2 новых варианта для каждого существующего примера. Каждый вариант будет иметь уникальный `id` (например `navbar-example-2`, `navbar-example-3`) и отличаться содержимым, стилями или структурой.

2. Массив `BLOCK_EXAMPLE_CATEGORIES` -- обновить `ids` в каждой категории, добавив новые id вариантов:
   - "Структура сайта": `['navbar-example', 'navbar-example-2', 'navbar-example-3', 'footer-example', 'footer-example-2', 'footer-example-3', 'three-steps', 'three-steps-2', 'three-steps-3']`
   - и аналогично для остальных 4 категорий.

3. Всего будет добавлено ~34 новых примера (по 2 дополнительных на каждый из 17 существующих типов).

4. Новые варианты будут отличаться:
   - Текстовым содержимым (разные тексты, цифры, названия)
   - Стилями (разные цвета фона, размеры шрифтов)
   - Структурой (разное кол-во элементов, разные комбинации блоков)

### Никаких других файлов менять не потребуется
Компонент `BlockExamplesList` уже поддерживает любое кол-во id в категориях, сетка 2 колонки адаптируется автоматически.
