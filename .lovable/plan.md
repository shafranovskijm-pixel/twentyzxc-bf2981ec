## Цель
Сделать в админке отдельный пункт меню «Акты сверки» (иконка в боковой панели), чтобы функционал был очевиден и не прятался внутри вкладки «Документы».

## Что сделаю

### 1. Новый пункт в сайдбаре
Файл: `src/components/admin/AdminSidebar.tsx`
- Добавлю в `defaultMenuItems` пункт `{ id: "reconciliation", label: "Акты сверки", icon: FileSpreadsheet }` (Lucide).
- Поставлю его сразу после «Документы», чтобы по смыслу шло рядом.

### 2. Новый компонент-обёртка
Файл: `src/components/admin/ReconciliationTab.tsx` (новый)
- Отдельная страница «Акты сверки», полностью посвящённая этому типу документа:
  - Шапка с описанием и кнопкой «Создать акт сверки».
  - Список ранее сохранённых актов сверки (фильтр `generated_documents.doc_type = 'reconciliation'`) с поиском по клиенту и периоду, действиями: открыть, PDF, отправить в Telegram/Email, удалить.
  - Форма создания/редактирования: выбор клиента, период «с/по», начальное сальдо, кнопка «Подтянуть из CRM» (договоры/акты в дебет, оплаты в кредит), ручное добавление/правка/удаление строк, авто-расчёт итогов и «сумма прописью», превью, печать PDF, подпись/печать, сохранение, отправка.
- Чтобы не дублировать код — переиспользую уже сделанные функции из `DocumentsTab` и `src/lib/reconciliation-template.ts`.

### 3. Рефактор: вынести логику сверки из DocumentsTab
Файл: `src/components/admin/DocumentsTab.tsx`
- Из `DocType` уберу `reconciliation` (теперь живёт в отдельной вкладке).
- Уберу из выпадашки тип документа «Акт сверки» и связанные поля (период, сальдо, строки) — чтобы у пользователя не было двух мест с одной и той же кнопкой.
- Логику загрузки CRM/рендеринга оставлю в общем хелпере (`src/lib/reconciliation-template.ts` уже есть; добавлю туда `loadReconciliationFromCRM`, который сейчас в DocumentsTab), чтобы новый `ReconciliationTab` им пользовался.

### 4. Подключение в Admin
Файл: `src/pages/Admin.tsx`
- Импорт `ReconciliationTab`.
- В `sectionTitles` добавлю `reconciliation: "Акты сверки"`.
- Рендер: `{activeSection === "reconciliation" && <ReconciliationTab />}`.
- Уже существующий обработчик `admin:navigate` оставлю — при необходимости можно будет открывать вкладку из CRM кнопкой «Сделать акт сверки».

### 5. Кнопка «Сделать акт сверки» в карточке клиента (бонус, маленькая)
Файл: `src/components/admin/ClientsTab.tsx` — добавлю в действия клиента пункт, который диспатчит `admin:navigate` с `section: "reconciliation"` и `clientId`, чтобы форма открылась сразу с выбранным клиентом.

## Технические детали
- Сохранение в той же таблице `generated_documents`, поле `doc_type='reconciliation'`, метаданные (период, сальдо, строки) — в JSON-полях, как сейчас.
- PDF, Telegram-доставка, email, подпись/печать — через существующие утилиты (`pdf`, `resend-contract`, edge-функции), без новых секретов.
- Никаких миграций БД не требуется.

## Результат
В левом сайдбаре админки появится новая иконка «Акты сверки» — отдельный раздел со списком, созданием, авто-подтягиванием данных из CRM, печатью и отправкой. В разделе «Документы» этот тип больше не дублируется.
