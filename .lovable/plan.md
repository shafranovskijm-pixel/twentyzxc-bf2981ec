

## Plan: Полноценные темы оформления админ-панели

### Что делаем

Заменить «Готовые баннеры» на **5 полноценных тем**, каждая из которых меняет ВСЁ: фон, баннер, цвет акцентов (кнопки, бейджи, ссылки), стиль карточек, хедера и анимации.

### 5 тем

| Тема | Фон | Акцент | Баннер | Анимация |
|------|-----|--------|--------|----------|
| 🍉 **Свежесть** | Белый/светло-зелёный | Emerald-500 | Арбузы/зелень | Плавающие листья |
| 🏢 **Офис** | Светло-серый, минимализм | Slate-600 | Ноутбук | Мягкий fade |
| 🌆 **Нью-Йорк** | Тёмно-серый индустриальный | Amber-500 | Небоскрёбы | Мерцающие огни |
| 🌅 **Закат** | Тёплый градиент | Orange-500 | Пляж | Плавный градиент-shift |
| 🌿 **Минимализм** | Пастельный лавандовый | Violet-400 | Горы | Нежное свечение |

### Как работает

1. **Новый тип `AdminTheme`** — объект с полями:
   - `id`, `label`, `bannerUrl`
   - `bgClass` — класс фона для всего layout
   - `headerClass` — стиль хедера
   - `cardClass` — стиль карточек (border, bg)
   - `accentColor` — CSS custom property для кнопок
   - `sidebarClass` — стиль сайдбара
   - `animationElement` — React-компонент (опционально) для фоновой анимации (частицы, мерцание)

2. **CSS custom properties** — при выборе темы устанавливаем `--theme-accent`, `--theme-bg`, `--theme-card` через `style` на корневом `div`. Кнопки и акценты подхватывают автоматически.

3. **Секция «Оформление»** — вместо отдельных «Готовые баннеры» и «Фон панели» будет единая сетка из 5 тем-превью. Клик на тему меняет сразу всё. Сохраняется в `localStorage` (`admin-active-theme`).

4. Остаётся возможность вручную загрузить свой баннер и выбрать светлую/тёмную базу.

### Файлы
