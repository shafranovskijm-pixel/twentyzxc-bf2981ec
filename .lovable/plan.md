

## План: CRM-модуль в админке

Добавляем три новых раздела в админ-панель: **Клиенты**, **Договоры (таблица)** и **Файлы договоров**.

### 1. Новые таблицы в базе данных

**`clients`** — справочник клиентов:
- `id`, `name` (название организации), `contact_person`, `phone`, `email`, `telegram`, `notes`, `created_at`, `updated_at`
- RLS: только admin может CRUD, чтение тоже только admin

**`contracts`** — учёт договоров (по структуре второй таблицы):
- `id`, `client_name` (текст, не FK — для гибкости), `contract_number`, `contract_date`, `payment_status` (текст: "оплачено", "не оплачено", etc.), `amount` (numeric), `amount_extra` (numeric, вторая сумма), `contract_type` (текст: "фрдо", etc.), `responsible` (текст), `notes`, `created_at`, `updated_at`
- RLS: только admin

**Storage bucket `contracts`** — для загрузки PDF/Word файлов договоров:
- Приватный бакет, доступ только admin
- Колонка `file_path` в таблице `contracts` для привязки файла

### 2. Изменения в `src/pages/Admin.tsx`

Расширяем табы с 3 до 6: SEO и OG | Контакты | Акции | **Клиенты** | **Договоры** | **Файлы**

Или логичнее — объединить Договоры + Файлы в один таб:

**Табы: SEO и OG | Контакты | Акции | Клиенты | Договоры**

**Таб «Клиенты»:**
- Таблица со списком клиентов (имя, контактное лицо, телефон, email)
- Кнопка «Добавить клиента» → форма в карточке
- Редактирование/удаление через кнопки в строке

**Таб «Договоры»:**
- Таблица: организация, номер договора, дата, статус оплаты, сумма, тип, ответственный
- Форма добавления/редактирования
- Загрузка файла договора (PDF/Word) через Storage API
- Кнопка скачивания файла в строке таблицы

1. **Миграция SQL** — создание таблиц `clients`, `contracts`, бакета `contracts`, RLS-политики
2. **`src/pages/Admin.tsx`** — добавить два новых таба с CRUD-интерфейсом
