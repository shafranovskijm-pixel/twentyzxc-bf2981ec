

## План: свайп + стрелки для смены темы на баннере (mobile-friendly)

### Что меняется
В админ-панели сверху есть декоративный баннер (под шапкой, `h-32`). Сейчас тема меняется только через `Профиль → Оформление`. Сделаю:

1. **Свайп влево/вправо по баннеру** — переключает тему (для тач-устройств).
2. **Две полупрозрачные стрелки `‹` / `›`** по краям баннера — кликабельные на любых устройствах.
3. **Лёгкая адаптация под телефон**: баннер чуть ниже (`h-24` на mobile, `h-32` на ≥sm), стрелки крупнее на мобильном, появляется маленькая «таблетка» с названием темы (`🍉 Свежесть`) внизу баннера на 1.5 сек после смены — пользователь видит, что переключилось.

### Логика переключения

Список тем для циклирования: `[null (По умолчанию), ...adminThemes]` — т.е. 7 вариантов. Свайп влево / стрелка → — следующая, свайп вправо / стрелка ← — предыдущая. Циклично (с конца на начало).

```text
[По умолчанию] ‹—› [🍉 Свежесть] ‹—› [🏢 Офис] ‹—› [🌆 Нью-Йорк] ‹—› [🌅 Закат] ‹—› [🌿 Минимализм] ‹—› [💎 Бирюза] ⤺
```

Используется существующий `handleThemeChange` — он уже сохраняет в localStorage, сбрасывает кастомный баннер и показывает toast. Тост от `handleThemeChange` достаточно информативен; дополнительный pill — это ненавязчивый визуальный фидбек прямо на баннере.

### UX-детали

- **Свайп**: `touchstart` фиксирует X, `touchend` сравнивает Δ. Порог — 50px. Вертикальный свайп игнорируется (если `|Δy| > |Δx|`).
- **Стрелки**: позиционируются `absolute left-2 / right-2`, `top-1/2`, размер `h-8 w-8` mobile / `h-9 w-9` desktop. Полупрозрачный фон `bg-black/30 hover:bg-black/50`, белая иконка `ChevronLeft/Right`. Не перекрывают существующие hover-кнопки «Изменить / Сбросить» (они в центре по hover).
- **Pill с названием**: `absolute bottom-2 left-1/2 -translate-x-1/2`, `bg-black/50 backdrop-blur text-white text-xs px-2.5 py-1 rounded-full`, появляется через `setTimeout` на 1500мс после клика/свайпа. Управляется локальным стейтом `themePillVisible`.
- **Кастомный баннер (`bannerUrl`)**: если у пользователя загружен свой баннер, свайп всё равно переключает тему — `handleThemeChange` уже корректно сбрасывает `bannerUrl`. Это ожидаемо: меняем тему — кастомный баннер уходит.
- **Не ломаем hover-оверлей «Изменить / Сбросить»**: стрелки имеют `z-10`, оверлей — `z-20` (он появляется только по hover, на тач-устройствах его всё равно нет).

### Реализация

В `src/pages/Admin.tsx`, блок `{/* Decorative banner */}` (строки 521–550):

1. Импортировать `ChevronLeft, ChevronRight` из `lucide-react` (если ещё не импортированы — `Check` уже импортирован, остальные подсмотрю).
2. Добавить локальный стейт: `const [themePillVisible, setThemePillVisible] = useState(false)` и ref для таймаута.
3. Добавить функцию `cycleTheme(direction: 1 | -1)`, которая:
   - формирует `themesList = [null, ...adminThemes]`,
   - находит индекс текущей `activeTheme` (или 0 если null),
   - вычисляет новый индекс по модулю,
   - вызывает `handleThemeChange(themesList[next])`,
   - запускает pill: `setThemePillVisible(true)` + `setTimeout(() => setVisible(false), 1500)`.
4. Добавить touch-handlers на корневой `<div>` баннера: `onTouchStart`, `onTouchEnd` (через ref для X/Y).
5. Внутри баннера добавить две `<button>` со стрелками и pill `<div>` с названием активной темы.
6. Уменьшить высоту: `className="h-24 sm:h-32 ..."`.
