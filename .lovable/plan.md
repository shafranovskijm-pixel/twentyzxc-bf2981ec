

## План: Фон как продолжение баннера + выпирающая картинка для Офиса

### Проблема
1. **Бирюза**: фон однотонный тёмный, не повторяет градиент баннера (от светлого бирюзового/серебристого к тёмному). Нужно чтобы фон страницы шёл тем же диапазоном цветов, что и баннер.
2. **Офис**: в правом нижнем углу картинка из баннера (цветок/растение) должна «выпирать из тумана» — более чёткая, менее размытая, чем остальные атмосферные элементы.

### Что делаю

#### 1. Бирюза — фон повторяет баннер (`src/data/admin-themes.ts`)

Расширить `bgClass` с полным градиентом от светлого бирюзового/серебристого вверху до глубокого тёмного внизу:

```
bgClass: "bg-gradient-to-b from-[#1a4a50] via-[#0a2028] to-[#050e12]"
```

Также обновить `headerClass` — слегка светлее с бирюзовым отливом, чтобы сверху ощущался тот же серебристо-бирюзовый тон, что на баннере.

#### 2. Офис — чёткая картинка в углу (`src/pages/Admin.tsx`)

Для темы `office` добавить специальную обработку нижнего правого фрагмента:
- **Меньше blur**: `blur(8px)` вместо `blur(20px)` — чтобы было видно растение
- **Больше opacity**: `0.25` — чтобы картинка реально «выпирала»
- **Градиентная маска**: от чёткого в углу к туману к центру
- Остальные 3 фрагмента остаются размытыми

#### 3. Тема-специфичная конфигурация атмосферы (`src/data/admin-themes.ts`)

Добавить в интерфейс `AdminTheme` опциональные поля для настройки атмосферных элементов per-theme:

```typescript
/** Override blur for bottom-right atmospheric fragment */
atmosphereBlur?: string;
/** Override opacity for bottom-right atmospheric fragment */
atmosphereOpacity?: number;
```

Для `office`: `atmosphereBlur: '8px'`, `atmosphereOpacity: 0.25`
Для `turquoise`: более яркие атмосферные элементы с меньшим blur для серебристого блеска.
