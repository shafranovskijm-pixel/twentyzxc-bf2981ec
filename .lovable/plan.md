

## План: тропический «закат + пальмы» вайб для главной страницы

### Концепция
Берём существующий баннер `banner-sunset.jpg` (закат + силуэты пальм) как вайб-референс и переносим его на главную (`/`). Новый месседж — «доверьте сайт нам — отдыхайте под пальмами». Золото (`#d4be37`) остаётся фирменным акцентом, но на фоне тёплых закатных тонов (оранжевый/розовый/коралл) — это даст премиум + «отпускное» настроение.

**Что НЕ трогаем:** 3D-сундук и ключи в секции контактов (`ContactSection`, `TreasureChest3D`, `InventoryBar`), достижения, админку, конструктор. Только публичная главная.

### Что меняется

**1. Новый AI-баннер для Hero (генерация через Nano Banana Pro)**
- Промпт: широкий (3840×1600) кинематографичный закат над океаном, силуэты тропических пальм по краям, тёплое оранжево-розово-золотое небо, мягкий градиент к тёмному низу для читаемости текста, премиум-настроение, no text. В стиле существующего `banner-sunset.jpg`, но шире и темнее снизу.
- Сохраняем как `src/assets/hero-tropical-sunset.jpg`.

**2. HeroSection — редизайн**
- Фон: новый баннер с тёмным градиент-оверлеем снизу (`bg-gradient-to-t from-background via-background/70 to-transparent`), сверху лёгкий vignette.
- Заголовок остаётся `24ZXC` золотой с шиммером (фирменный знак).
- Новая подача месседжа:
  - Tagline: `ПОД КЛЮЧ · ПОД ПАЛЬМАМИ` (вместо «Premium Digital Solutions»)
  - Подзаголовок: `Доверьте сайт, рекламу и приложения нам — а сами отдыхайте`
  - Описание: `Веб-разработка, реклама и веб-приложения премиум-класса. Полный цикл — от идеи до запуска`
- Декор: силуэты листьев пальмы в углах (через AI-сгенерированный PNG `palm-leaf.png` с прозрачным фоном) вместо геометрических ромбов/линий. На мобильных — скрываем (`hidden md:block`) по правилу из памяти.
- Кнопки CTA — оставляем как есть (`hero` / `heroOutline`), они и так золотые.
- ServiceStat внизу (01/02/03): подписи остаются, но появляется тонкая закатная линия-разделитель.

**3. Цветовая адаптация (только для главной, через локальный wrapper-класс `.tropical-vibe`)**
- Не трогаем глобальные CSS-переменные (это ломает админку и шаблоны).
- На `<div>` главной добавляем класс `tropical-vibe`, внутри которого:
  - Подкручиваем `--background` к более тёплому тёмному (`220 10% 10%` → `15 15% 9%`, чуть теплее).
  - Добавляем `--coral: 14 85% 65%` как вторичный акцент для секционных glow.
- Это чисто визуальный warm-tone tweak; золото остаётся главным.

**4. Декорации главной (`Index.tsx`)**
- `GradientGlows` → новый компонент `TropicalGlows` с тёплыми оранжево-коралловыми мягкими пятнами по углам.
- `GeometricShapes` оставляем (они хорошо ложатся), но снижаем opacity и красим в warm tone через wrapper.
- `InteractiveParticles` → красим частицы в золото + коралл (mix через random).
- `SectionDivider` варианты `ornate`/`diamond`/`simple` оставляем — они золотые и подходят.

**5. WebDevSection и PromotionSection — лёгкая адаптация (без переделки структуры)**
- Карточки услуг: добавляем тонкий warm-glow на hover (тёплое сияние снизу карточки) — через одну CSS-утилиту `.warm-card-glow`.
- Заголовки секций: пальмовый листочек-иконка слева от заголовка (маленький SVG, золотой).

**6. Шрифты**
- Текущие: `Playfair Display` (display) + `Inter` (body). Подходят, не меняем — они уже дают премиум-чувство.
- Добавляем один акцентный display для тропического слогана: вариант — оставить `Playfair Display` italic для tagline «Под ключ. Под пальмами.» — дешевле и стилистически цельнее, чем тащить новый шрифт.

**7. ContactSection — НЕ ТРОГАЕМ**
Сундук, ключи, 3D-сцена — остаются как есть. Только фон секции получит warm-glow снизу для плавного перехода от тропического Hero.

### AI-генерация (детали)
- Модель: `google/gemini-3-pro-image-preview` (Nano Banana Pro) — для максимального качества Hero-баннера.
- Сохранение: записываем base64 → `src/assets/hero-tropical-sunset.jpg` через `code--exec`.
- Для листа пальмы — отдельный запрос: `золотистый силуэт листа кокосовой пальмы, прозрачный фон, плоский, минималистичный, premium, PNG`.
