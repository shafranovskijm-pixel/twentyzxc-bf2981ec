

## План: Объединить SEO, Контакты, Акции и Реквизиты в «Настройки сайта»

### Суть
Сейчас в вертикальном меню профиля 4 отдельных пункта: SEO, Контакты, Акции, Реквизиты. Объединить их в один пункт **«Настройки сайта»** с внутренними секциями (аккордеон или вкладки).

### Что делаю

**`src/pages/Admin.tsx`:**

1. В массиве `profileTabs` заменить 4 пункта (seo, contacts, promotions, requisites) на один:
   ```
   { id: "site-settings", label: "Настройки сайта", icon: Settings }
   ```

2. Добавить новый блок `profileSubTab === "site-settings"` — единая страница, где все 4 раздела отображаются последовательно с заголовками-разделителями (карточки одна за другой):
   - SEO-настройки (ключевые слова, title, description, OG)
   - Контакты (email, телефон, Telegram)
   - Акции (создание/редактирование/список)
   - Реквизиты (компонент RequisitesTab)

3. Удалить отдельные блоки `profileSubTab === "seo"`, `"contacts"`, `"promotions"`, `"requisites"` — весь их контент переносится в `"site-settings"`.

4. Одна общая кнопка «Сохранить» внизу для SEO и контактов (акции сохраняются отдельно, реквизиты — через свой компонент).
