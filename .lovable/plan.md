
# Улучшения конструктора сайтов -- Обзор возможностей

## Текущее состояние

Конструктор уже включает: 19 типов блоков, drag-and-drop сортировку, undo/redo, облачное сохранение, шаблоны страниц, примеры блоков, предпросмотр на разных устройствах, загрузку изображений, анимации и hover-эффекты, настройки фона и шрифтов, публикацию по ссылке.

---

## Предложения по улучшению (от простого к сложному)

### 1. Экспорт в HTML
Кнопка "Скачать HTML" -- генерирует standalone HTML-файл со всеми стилями inline. Пользователь получает готовый файл, который можно разместить на любом хостинге.

### 2. Дублирование проекта
Кнопка "Дублировать" рядом с сохранением -- создаёт копию текущего проекта с новым slug. Полезно для создания вариаций.

### 3. История версий проекта
При каждом сохранении сохранять версию (timestamp). Показывать список версий с возможностью откатиться к любой. Реализуется через отдельную таблицу `playground_versions`.

### 4. Блок "Аккордеон / FAQ"
Новый тип блока с раскрывающимися вопросами-ответами. Формат контента: `Вопрос 1|Ответ 1\nВопрос 2|Ответ 2`.

### 5. Блок "Табы"
Переключаемые вкладки с разным содержимым. Формат: `Вкладка 1|Контент 1||Вкладка 2|Контент 2`.

### 6. Пользовательские цвета в палитре
Возможность сохранять свои цвета в палитру (localStorage). Кнопка "+" рядом с пресетами.

### 7. Слои блоков (layer list)
Панель "Структура страницы" -- список всех блоков в виде дерева с возможностью переименования, скрытия и быстрого перехода к блоку.

### 8. Загрузка проекта из файла
Кнопка "Импорт" -- загрузка JSON-файла с проектом. Дополняет существующий экспорт.

### 9. Адаптивные стили для блоков
Отдельные настройки fontSize/padding для мобильной и десктопной версии каждого блока.

### 10. SEO-настройки проекта
Поля для title, description, favicon опубликованного проекта. Сохраняются в БД и применяются на странице `/p/:slug`.

---

## Рекомендуемый порядок реализации

1. Экспорт в HTML -- быстро, высокая ценность для пользователя
2. Блок "Аккордеон/FAQ" -- востребованный тип контента
3. Слои блоков (layer list) -- улучшает UX при работе со сложными страницами
4. SEO-настройки проекта -- полезно для опубликованных страниц
5. Остальное по приоритету
