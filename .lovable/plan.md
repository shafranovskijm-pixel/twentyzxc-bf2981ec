

## План: Добавить кнопки «Сформировать Счёт» и «Сформировать Акт»

### Что изменится

В конструкторе документов (`DocumentsTab.tsx`, строки 1361–1364) сейчас одна кнопка «Сформировать [текущий тип]». Добавлю рядом ещё две кнопки, чтобы из одного и того же набора данных (клиент, услуги, реквизиты) можно было одним кликом сгенерировать **Счёт** и **Акт** — без необходимости переключать тип документа в селекторе сверху.

### Поведение

- **Основная кнопка** (как сейчас): «Сформировать {текущий тип}» — большая, primary.
- **Две дополнительные кнопки** под ней: «Сформировать Счёт» и «Сформировать Акт» — меньшего размера, `variant="outline"`.
- Если выбранный `docType` уже совпадает (например, это «Счёт»), соответствующая дополнительная кнопка скрывается, чтобы не дублировать.
- При клике вызывается тот же `generate()`, но с временной подменой типа: формируется HTML соответствующего шаблона (`generateInvoiceHtml` / `generateActHtml`) и открывается превью.

### Реализация

В `src/components/admin/DocumentsTab.tsx`:
1. Вынести логику `generate` так, чтобы можно было передать тип-override (или сделать обёртку `generateAs(type)`).
2. Под основной кнопкой добавить ряд из двух outline-кнопок с иконкой `Printer`.
3. Скрывать кнопку, тип которой = текущему `docType`.
