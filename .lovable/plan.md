
# Добавление новых шаблонов и примеров блоков

## Что будет сделано

### 1. Новые шаблоны страниц (добавляются к существующим 4)

| Шаблон | Описание | Использует блоки |
|--------|----------|------------------|
| **Резюме** | Страница-резюме с навыками и опытом | list, counter, quote, heading, text, divider |
| **Ресторан** | Меню и атмосфера заведения | image, list, card, heading, quote, button |
| **Событие** | Анонс мероприятия / конференции | counter, heading, text, button, list, video |
| **Стартап** | Презентация стартапа с метриками | counter, card, image, heading, text, button |

### 2. Секция "Примеры блоков" под шаблонами

Новая секция в левом сайдбаре с готовыми пре-настроенными блоками, которые добавляются одним кликом. Каждый пример -- это конкретный блок с уже настроенными стилями, анимацией и контентом:

- **Статистика 3 колонки** -- три счётчика рядом (3 блока counter)
- **Отзыв клиента** -- стилизованная цитата с hover-glow
- **Список преимуществ** -- список с иконками-эмодзи
- **FAQ карточка** -- карточка вопрос-ответ
- **YouTube видео** -- предзаполненный video блок
- **Герой-заголовок** -- крупный заголовок + подзаголовок (2 блока)
- **CTA секция** -- заголовок + текст + кнопка (3 блока)
- **Галерея** -- 2 изображения с hover-эффектами

### Детали реализации

1. **ProjectTemplates.tsx**: Расширить массив `PAGE_TEMPLATES` 4 новыми шаблонами, каждый из которых активно использует новые типы блоков (list, quote, counter, video). Добавить новый массив `BLOCK_EXAMPLES` с готовыми пресетами блоков. Отрисовать секцию "Готовые примеры" под шаблонами с кнопками для вставки.

2. **use-playground.tsx**: Добавить метод `addBlocks(blocks)` -- принимает массив блоков без id, генерирует id, добавляет в конец текущего списка (в отличие от `loadTemplate`, который заменяет все блоки).

3. **Playground.tsx**: Передать `addBlocks` в `ProjectTemplates` для вставки примеров без замены текущих блоков.

Все новые шаблоны будут использовать градиентные фоны, разнообразные анимации (blur-in, scale-bounce, fade-in-left/right) и hover-эффекты для демонстрации возможностей конструктора.
