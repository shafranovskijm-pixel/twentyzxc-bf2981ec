

## План: Полная интеграция помощника НМО — пошаговый мастер с автозаполнением через расширение

### Концепция
Превращаем вкладку «НМО Портал» в **пошаговый мастер регистрации** с интерактивным трекером 10 этапов, расширенными данными организации и ответственного, авто-генерацией PDF-документов и **Chrome-расширением** для автозаполнения полей на сайтах nmfo-vo / org.edu.rosminzdrav.

---

### Часть 1. Расширение схемы данных (БД)

Добавляю в таблицу `nmo_registrations` поля по инструкции Минздрава:

**Организация:**
- `ogrn` (text), `legal_address`, `actual_address` (text)
- `organization_abbr` (text) — устойчивая аббревиатура
- `organization_phone`, `organization_email`, `organization_website` (text)
- `region` (text)
- `has_dpo_appendix` (boolean) — приложение о ДПО
- `application_number` (text), `application_date` (date) — номер/дата заявки на портале
- `mail_track_number` (text), `mail_sent_date` (date) — почтовое отправление оригиналов

**Ответственное лицо:**
- `responsible_birth_date` (date), `responsible_gender` (text: M/Ж)
- `responsible_mobile` (text), `responsible_work_phone` (text)
- `responsible_main_workplace` (text), `responsible_region` (text)
- `responsible_login` (text), `responsible_password` (text) — после регистрации на портале

**Этапы (расширенный чеклист — 10 пунктов):**
```
1. employee_registered     — Сотрудник зарегистрирован на nmfo-vo (физлицо)
2. email_confirmed         — Подтверждён e-mail (письмо со ссылкой)
3. credentials_received    — Получены логин/пароль для НМФО
4. lk_org_request_started  — Создана заявка на org.edu (Первичная подача)
5. org_data_filled         — Заполнены данные организации
6. responsible_added       — Добавлено ответственное лицо
7. docs_generated          — Сгенерированы Заявление + Обязательство
8. docs_uploaded           — Сканы загружены, статус «Подана»
9. originals_sent          — Оригиналы + копия лицензии отправлены почтой в РНИМУ
10. cabinet_opened         — ЛК организации открыт методистом
11. dpp_passports_filled   — Паспорта ДПП заполнены (доп. этап)
```

**Новая таблица `nmo_documents`** для хранения сгенерированных PDF (Заявление, Обязательство, скан лицензии):
```
id, registration_id, doc_type ('application' | 'obligation' | 'license_scan' | 'other')
file_path, file_name, file_size, created_at
```
Bucket `nmo-documents` (приватный, RLS — только админ).

### Часть 2. UI пошагового мастера в `NmoTab.tsx`

В раскрытой карточке заявки — **вертикальный stepper из 11 шагов**. Каждый шаг:
- Номер + название + статус (✅ done / ▶ active / ⚪ pending)
- Раскрывающийся блок с инструкцией (выдержка из официальной инструкции Минздрава, с прямыми ссылками на нужный экран портала)
- **Кнопка действия** в зависимости от шага:
  - Шаг 1 → «Открыть форму регистрации НМФО» + «📋 Скопировать данные» (по полям)
  - Шаг 4 → «Открыть org.edu.rosminzdrav.ru» + «Включить расширение для автозаполнения»
  - Шаг 7 → «Скачать Заявление PDF» + «Скачать Обязательство PDF»
  - Шаг 9 → форма ввода трек-номера Почты России + дата отправки
  - и т.д.
- Чекбокс «Шаг выполнен»

Прогресс-бар сверху: «Этап 5 из 11 • 45%».

### Часть 3. Chrome-расширение «НМО Автозаполнение»

Создаю папку `extension/` с MV3-расширением:

**Файлы:**
- `manifest.json` — права `activeTab`, `storage`, content_scripts на `nmfo-vo.edu.rosminzdrav.ru` и `org.edu.rosminzdrav.ru`
- `popup.html` + `popup.js` — выбор активной заявки (синхронизация через `chrome.storage.local`)
- `content.js` — детект текущей формы по URL/полям, автозаполнение `<input>` через DOM с симуляцией событий React (`nativeInputValueSetter`)
- `background.js` — приём данных от вашего сайта через `chrome.runtime.onMessageExternal` (whitelist 24zxc.ru)
- `icon.png` (золотая Σ-иконка)

**Поток работы:**
1. В админке нажимаете «Передать в расширение» на карточке заявки → site посылает данные расширению
2. Открываете портал НМФО → в попапе расширения видна нужная заявка → жмёте «Заполнить эту страницу»
3. Расширение находит поля по `name`/`id`/`placeholder`, заполняет их
4. Капчу и финальную отправку делаете руками (по правилам портала)

**Сборка и доставка:**
- Скрипт `nix run nixpkgs#zip -- -r public/nmo-extension.zip extension/`
- В админке кнопка «Скачать расширение» (через fetch+blob) + инструкция по установке (Developer mode → Load unpacked)

### Часть 4. Генерация PDF: Заявление + Обязательство

Edge-функция `generate-nmo-documents`:
- Принимает `registration_id`
- Достаёт данные из `nmo_registrations`
- Использует HTML-шаблоны (как в `frdo-contract-template.ts`) с подстановкой плейсхолдеров
- На клиенте — html2canvas + jsPDF (как в DocumentsTab) → загрузка в bucket `nmo-documents` → запись в `nmo_documents`
- Кнопка «Скачать» / «Открыть» / «Перегенерировать»

Шаблоны (берём из инструкции, разделы 3.7, 3.10):
- **Заявление на открытие ЛК** — реквизиты организации, ОГРН, ИНН, КПП, юр.адрес, лицензия, данные ответственного, место для подписи руководителя + печать
- **Обязательство о неразглашении персональных данных** — ФИО ответственного, СНИЛС, дата рождения, должность, обязательства

### Часть 5. Полезные мелочи

- Кнопка «📋 Скопировать в буфер» рядом с каждым полем заявки (для ручной вставки на портал)
- Прямые deep-ссылки на экраны портала: `https://nmfo-vo.edu.rosminzdrav.ru/#/registration`, `https://org.edu.rosminzdrav.ru`, `https://nsi.rosminzdrav.ru/...` (для OID)
- В карточке — статусы заявки портала (Формируется / Подана / На обработке / На доработке / Отклонена / Закрыта) с цветовой индикацией
- Telegram-уведомление при переходе на финальный этап (через существующий `send-telegram`)
- Иконка-ссылка на инструкцию Минздрава 07.05.2024 рядом с каждым шагом
